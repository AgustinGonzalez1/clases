### 🪙 Parte 1: Nombre de la parte

### Paso 1: Crear el objeto

Click derecho en **Workspace** → Insert Object (**Insertar objeto**) → **Part**, la renombrás `Moneda`.

> 📝 **Qué es un Objeto:** qué es y para qué lo usamos, en una o dos líneas.

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Propiedad1** ✏️ | `valor` | Para qué sirve, corto |
| **Propiedad2** ✏️ | `valor` | Para qué sirve, corto |
| **Propiedad3** | `valor` | Una que no se cambia, pero que el alumno va a ver |

Las demás (PropiedadX, PropiedadY…) quedan como vienen.

### Paso 2: El código

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `NombreScript`:

```lua
local Players = game:GetService("Players")      -- comentario corto, sin tildes

local function hacerAlgo(jugador)
    print(jugador.Name)                          -- que hace esta linea
end

Players.PlayerAdded:Connect(hacerAlgo)          -- cuando pasa esto, llama a la funcion
```

- `hacerAlgo` hace tal cosa
- `PlayerAdded` avisa cuando entra un jugador
