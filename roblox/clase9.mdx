# Clase 9: Programación creativa 🎨🎮

Con todo lo aprendido, esta clase es libre: cada alumno crea el bloque que quiera aplicando métodos, propiedades y eventos.

## Objetivos

- Repasar los 3 pilares del scripting: propiedad, método y evento
- Crear distintos tipos de bloques interactivos
- Aplicar `BodyVelocity` para mover al jugador

## Contenido

### 1. Repasar los 3 pilares

Cualquier bloque que crees tiene que usar:

| Pilar | Ejemplos |
|---|---|
| **Propiedad** | Color, Size, Transparency, WalkSpeed |
| **Método** | Clone(), Destroy() |
| **Evento** | Touched, TouchEnded |

### 2. Bloque invisible

```lua
local bloque = script.Parent

bloque.Touched:Connect(function()
    bloque.Transparency = 1
end)

bloque.TouchEnded:Connect(function()
    bloque.Transparency = 0
end)
```

### 3. Bloque que se achica

```lua
local bloque = script.Parent

bloque.Touched:Connect(function()
    bloque.Size = bloque.Size - Vector3.new(0.5, 0.5, 0.5)
end)
```

### 4. Bloque que aumenta la velocidad

```lua
local bloque = script.Parent

bloque.Touched:Connect(function(mano)
    local humanoid = mano.Parent.Humanoid
    humanoid.WalkSpeed = 50
end)

bloque.TouchEnded:Connect(function(mano)
    local humanoid = mano.Parent.Humanoid
    wait(0.5)   -- evita el problema del rebote
    humanoid.WalkSpeed = 16
end)
```

### 5. Bloque que te empuja hacia un lugar

Este bloque mueve al jugador automáticamente en una dirección usando `BodyVelocity`.

```lua
local bloque = script.Parent

bloque.Touched:Connect(function(mano)
    local personaje = mano.Parent
    local rootPart = personaje.HumanoidRootPart

    local empuje = Instance.new("BodyVelocity")
    empuje.Velocity = Vector3.new(50, 0, 0)              -- empuja hacia el eje X
    empuje.MaxForce = Vector3.new(math.huge, 0, math.huge)
    empuje.Parent = rootPart

    wait(0.5)
    empuje:Destroy()   -- deja de empujar
end)
```

- `BodyVelocity` es un objeto que aplica una fuerza constante sobre una Part
- `Velocity` define la dirección y velocidad del empuje
- `MaxForce` controla en qué ejes aplica esa fuerza. `math.huge` significa "sin límite de fuerza"
- Se destruye después de un tiempo para que el empuje no sea infinito

## Ejercicio

> Consigna: Aplicá métodos, propiedades y eventos en un bloque propio, original y distinto a los ejemplos vistos.

**Pistas:**
1. Combiná al menos una propiedad, un método y un evento en tu bloque
2. Podés mezclar ideas de los ejemplos (por ejemplo invisible + empuje)
3. Probá tu bloque varias veces para asegurarte que no se rompe al tocarlo repetidas veces
