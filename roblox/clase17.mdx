# Clase 17: Efectos y Pulido Visual ✨

Agregamos partículas, luces y efectos visuales para darle vida al juego.

## Objetivos

- Conocer los efectos visuales disponibles en Roblox: Fire, Smoke, Sparkles, PointLight, ParticleEmitter
- Combinar efectos para lograr resultados realistas
- Controlar efectos desde código con la propiedad Enabled

## Contenido

### 1. Agregar Fire

1. Seleccionás una Part → Insert Object → **Fire**

| Propiedad | Qué controla |
|---|---|
| **Heat** | Intensidad del fuego |
| **Size** | Tamaño de las llamas |
| **Color / SecondaryColor** | Colores base y punta del fuego |

### 2. Agregar Smoke

1. Seleccionás una Part → Insert Object → **Smoke**

| Propiedad | Qué controla |
|---|---|
| **Color** | Color del humo |
| **Opacity** | Qué tan denso es |
| **RiseVelocity** | Qué tan rápido sube |
| **Size** | Tamaño de las partículas |

### 3. Agregar Sparkles y PointLight

1. Insert Object → **Sparkles** (**SparkleColor** controla el color)
2. Insert Object → **PointLight** (**Brightness**, **Range**, **Color**)

**Ejemplo:** Fire + PointLight naranja = antorcha realista. Fire + Smoke = fogón o volcán.

### 4. Agregar un ParticleEmitter

1. Insert Object → **ParticleEmitter**

| Propiedad | Qué controla |
|---|---|
| **Rate** | Partículas por segundo |
| **Lifetime** | Cuánto dura cada partícula |
| **Speed** | Velocidad de las partículas |

### 5. Controlar efectos con código

```lua
local bloque = script.Parent
local fuego = bloque:FindFirstChild("Fire")  -- referencia al efecto Fire

bloque.Touched:Connect(function()
    fuego.Enabled = true    -- activa el fuego al tocar el bloque
end)

bloque.TouchEnded:Connect(function()
    fuego.Enabled = false   -- desactiva el fuego al soltar
end)
```

## Ejercicio

> Consigna: Aplicá 3 efectos visuales distintos para acciones clave de tu juego (por ejemplo una antorcha, un portal mágico, o un objeto coleccionable).

**Pistas:**
1. Combiná al menos un efecto de partículas con un PointLight
2. Probá controlar uno de los efectos con código usando `Enabled`
3. Ajustá Color y Size hasta que se vea bien en tu mapa
