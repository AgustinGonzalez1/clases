# Clase 5: Tu Propio Personaje: Rig Personalizado + Animación 🧍‍♂️✨

Construimos un personaje propio con Parts, lo convertimos en un rig animable y lo animamos con el Animation Editor.

## Objetivos

- Construir un personaje con las 6 partes básicas
- Conectar las partes con Motor6D para armar un rig
- Animar el rig propio con el Animation Editor

## Contenido

### 1. Construir las 6 partes

Creás las siguientes Parts y las nombrás exactamente así:

| Parte | Nombre en Studio |
|---|---|
| Cuerpo central | `HumanoidRootPart` |
| Cabeza | `Head` |
| Brazo izquierdo | `LeftArm` |
| Brazo derecho | `RightArm` |
| Pierna izquierda | `LeftLeg` |
| Pierna derecha | `RightLeg` |

> ⚠️ Activá **Anchored = true** en todas mientras construís.

### 2. Agregar el Humanoid

1. Agrupás todas las Parts en un **Model** (Ctrl+G)
2. Click derecho sobre el Model → Insert Object → **Humanoid**

### 3. Conectar las partes con Motor6D

El Motor6D va en la parte **desde donde sale la conexión**.

| Motor6D va en... | Part0 | Part1 |
|---|---|---|
| HumanoidRootPart | HumanoidRootPart | Head |
| HumanoidRootPart | HumanoidRootPart | LeftArm |
| HumanoidRootPart | HumanoidRootPart | RightArm |
| HumanoidRootPart | HumanoidRootPart | LeftLeg |
| HumanoidRootPart | HumanoidRootPart | RightLeg |

**Ejemplo:** para conectar la cabeza, seleccionás **HumanoidRootPart** → Insert Object → **Motor6D** → `Part0 = HumanoidRootPart` / `Part1 = Head`.

> 💡 **Motor6D es el método vigente para rigs personalizados armados con Parts.** Roblox introdujo un sistema nuevo llamado AnimationConstraint, pero ese solo reemplaza a Motor6D en el personaje estándar del jugador (R15). Para un rig propio como este, Motor6D sigue siendo el método correcto y recomendado por la documentación oficial.

### 4. Asignar el PrimaryPart

1. Seleccionás el **Model**
2. Properties → **PrimaryPart** → seleccionás **HumanoidRootPart**

### 5. Animar el rig

1. **Avatar → Animation Editor**
2. Seleccionás el Model
3. El editor detecta las uniones y te deja mover cada parte
4. Creás los keyframes y publicás

### 6. Problemas comunes

| Problema | Causa |
|---|---|
| Animation Editor no muestra las partes | Falta el Humanoid o Motor6D mal configurados |
| El modelo no se posiciona bien | PrimaryPart no asignado |

## Ejercicio

> Consigna: Creá un rig personalizado y hacé al menos 1 animación funcional (idle, caminar o saludo).

**Pistas:**
1. Nombrá las 6 partes exactamente como en la tabla, Roblox depende de esos nombres
2. Verificá que cada Motor6D tenga Part0 y Part1 bien configurados antes de animar
3. Si el Animation Editor no muestra las partes, revisá que el Humanoid esté agregado
