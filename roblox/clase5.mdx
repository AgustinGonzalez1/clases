# Clase 5: Tu Propio Personaje: Rig Personalizado + Animación 🧍‍♂️✨

Construimos un personaje propio con Parts, lo convertimos en un rig animable y lo animamos con el Animation Editor.

## Objetivos

- Construir un personaje con las 6 partes básicas
- Conectar las partes con Motor6D para armar un rig
- Animar el rig propio con el Animation Editor

## Contenido

### 1. Construir las 6 partes

Creás las siguientes Parts y las nombrás exactamente así:

| Parte | Nombre en Studio |
|---|---|
| Cuerpo central | `HumanoidRootPart` |
| Cabeza | `Head` |
| Brazo izquierdo | `LeftArm` |
| Brazo derecho | `RightArm` |
| Pierna izquierda | `LeftLeg` |
| Pierna derecha | `RightLeg` |

> ⚠️ Activá **Anchored = true** en todas mientras construís.

### 2. Agregar el Humanoid

1. Agrupás todas las Parts en un **Model** (Ctrl+G)
2. Click derecho sobre el Model → Insert Object → **Humanoid**

### 3. Conectar las partes con Motor6D

El Motor6D va en la parte **desde donde sale la conexión**.

| Motor6D va en... | Part0 | Part1 |
|---|---|---|
| HumanoidRootPart | HumanoidRootPart | Head |
| HumanoidRootPart | HumanoidRootPart | LeftArm |
| HumanoidRootPart | HumanoidRootPart | RightArm |
| HumanoidRootPart | HumanoidRootPart | LeftLeg |
| HumanoidRootPart | HumanoidRootPart | RightLeg |

**Ejemplo:** para conectar la cabeza, seleccionás **HumanoidRootPart** → Insert Object → **Motor6D** → `Part0 = HumanoidRootPart` / `Part1 = Head`.

> 💡 **Motor6D es el método vigente para rigs personalizados armados con Parts.** Roblox introdujo un sistema nuevo llamado AnimationConstraint, pero ese solo reemplaza a Motor6D en el personaje estándar del jugador (R15). Para un rig propio como este, Motor6D sigue siendo el método correcto y recomendado por la documentación oficial.

### 4. Ajustar el punto de giro con el plugin RigLink

Si al conectar el Motor6D todo el brazo "salta" al centro del torso, es el comportamiento normal de Roblox cuando C0/C1 quedan en su valor por defecto (sin ningún desplazamiento). Calcular esos valores a mano con matemática es un proceso muy propenso a errores, así que en vez de eso usamos un plugin gratuito llamado **RigLink**, que hace el trabajo de forma visual.

**Paso 1: Instalar el plugin**

1. Pestaña **Vista** → **Toolbox** (Caja de herramientas)
2. En el panel que se abre, hacés click en el ícono de **☰** (arriba a la izquierda) y elegís la categoría **Plugins**
3. Buscás **"RigLink"**
4. Lo instalás (es gratis)

**Paso 2: Conectar las partes**

1. Activás el plugin desde la pestaña **Plugins**
2. Seleccionás las dos partes a unir (por ejemplo `HumanoidRootPart` y `RightArm`, con Ctrl+click)
3. Aparecen los handles (flechas roja, verde y azul) en el punto donde el plugin sugiere la unión
4. Hacés click en **"Link Selected"**

El plugin crea el Motor6D con los C0/C1 correctos automáticamente, sin que el brazo se mueva de lugar.

**Paso 3: Ajustar el punto de giro manualmente (si hace falta)**

Si el punto sugerido no queda exactamente en el hombro:

1. Activás **"Manual Alignment"** en el panel del plugin
2. Volvés a seleccionar las dos partes
3. Arrastrás los handles hasta la posición real donde debería estar la unión
4. Click en **"Link Selected"** de nuevo para aplicar

> 💡 El punto de giro (pivote) es lo que hace que el brazo cuelgue naturalmente desde el hombro al animarlo, en vez de girar "flotando" desde su propio centro.

Repetís este proceso para cada parte: `Head`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg`, todas conectadas al `HumanoidRootPart`.

### 5. Asignar el PrimaryPart

1. Seleccionás el **Model**
2. Properties → **PrimaryPart** → seleccionás **HumanoidRootPart**

### 6. Animar el rig

1. **Avatar → Animation Editor**
2. Seleccionás el Model
3. El editor detecta las uniones y te deja mover cada parte
4. Creás los keyframes y publicás

### 7. Problemas comunes

| Problema | Causa |
|---|---|
| Animation Editor no muestra las partes | Falta el Humanoid o Motor6D mal configurados |
| El modelo no se posiciona bien | PrimaryPart no asignado |
| El brazo salta al centro del torso al conectarlo | C0/C1 en su valor default; usá RigLink (Paso 4) para conectarlo sin que se mueva |
| El brazo gira desde el medio en vez del hombro | El punto de giro no está en el hombro; ajustalo con "Manual Alignment" en RigLink |

## Ejercicio

> Consigna: Creá un rig personalizado y hacé al menos 1 animación funcional (idle, caminar o saludo).

**Pistas:**
1. Nombrá las 6 partes exactamente como en la tabla, Roblox depende de esos nombres
2. Usá el plugin **RigLink** para conectar las partes sin que salten de lugar
3. Si el punto de giro no queda en el hombro, usá "Manual Alignment" para ajustarlo a mano
4. Si el Animation Editor no muestra las partes, revisá que el Humanoid esté agregado
