# Clase 5: Tu Propio Personaje: Rig Personalizado + Animación 🧍‍♂️✨

Construimos un personaje propio con Parts, lo convertimos en un rig animable y lo animamos con el Animation Editor.

## Objetivos

- Construir un personaje con 6 piezas visibles y una raíz invisible
- Conectar las partes con Motor6D para armar un rig
- Animar el rig propio con el Animation Editor

## Contenido

### 1. Construir las partes

Usamos un **rig personalizado** para este muñeco. Creás las siguientes Parts:

| Parte | Nombre en Studio |
|---|---|
| Cuerpo central | `Torso` |
| Raíz invisible | `HumanoidRootPart` |
| Cabeza | `Head` |
| Brazo izquierdo | `LeftArm` |
| Brazo derecho | `RightArm` |
| Pierna izquierda | `LeftLeg` |
| Pierna derecha | `RightLeg` |

> ⚠️ Activá **Anchored = true** en todas mientras construís.

La raíz es una Part aparte, del tamaño del torso y en su misma posición, con **Transparency = 1** y **CanCollide = false**. El torso sigue visible.

### 2. Agregar el Humanoid

1. Agrupás todas las Parts en un **Model** (Ctrl+G)
2. Click derecho sobre el Model → Insert Object → **Humanoid**; verificás **RigType = R6**
3. Si no tiene un **Animator**, lo insertás dentro del Humanoid

### 3. Conectar las partes con Motor6D

Esta tabla es la referencia para conectar con RigLink en el paso siguiente. **No crees antes los Motor6D manualmente.**

| Nombre del Motor6D | Va en / Part0 | Part1 |
|---|---|---|
| RootJoint | HumanoidRootPart | Torso |
| Neck | Torso | Head |
| LeftShoulder | Torso | LeftArm |
| RightShoulder | Torso | RightArm |
| LeftHip | Torso | LeftLeg |
| RightHip | Torso | RightLeg |

> 💡 Motor6D sigue siendo válido para este rig de Parts. En este muñeco, Head se conecta a Torso mediante Neck.

### 4. Ajustar el punto de giro con el plugin RigLink

**RigLink** crea los Motor6D conservando la posición de las piezas y permite elegir visualmente el punto de giro.

**Paso 1: Instalar el plugin**

1. Abrís la [publicación de RigLink de IrishFix](https://devforum.roblox.com/t/riglink-%E2%80%93-a-simple-smarter-way-to-rig-models-in-studio-now-free/3680684)
2. Desde su enlace al Creator Store, instalás el plugin gratuito
3. Lo abrís en Studio desde **Plugins**

**Paso 2: Conectar las partes**

1. Activás el plugin desde la pestaña **Plugins**
2. Seleccionás las dos partes a unir (por ejemplo `Torso` y `RightArm`, con Ctrl+click)
3. Aparecen los handles (flechas roja, verde y azul) en el punto donde el plugin sugiere la unión
4. Confirmás la conexión y revisás el nombre, Part0 y Part1 del Motor6D según la tabla

Creás cada unión una sola vez. Para la raíz y el torso, el punto de unión queda en su centro compartido.

**Paso 3: Ajustar el punto de giro manualmente (si hace falta)**

Si el punto sugerido no queda exactamente en el hombro:

1. Antes de confirmar la conexión, activás **Manual Alignment**
2. Arrastrás el punto de giro al hombro; si necesitás moverlo libremente, desactivás **Lock Alignment**
3. Confirmás la unión. Si ya habías creado una incorrecta, deshacela antes de repetir

> 💡 El punto de giro (pivote) es lo que hace que el brazo cuelgue naturalmente desde el hombro al animarlo, en vez de girar "flotando" desde su propio centro.

Repetís las conexiones de la tabla: cabeza y extremidades al **Torso**, y Torso a **HumanoidRootPart**. Los pivotes van en el cuello, los hombros y las caderas.

### 5. Asignar el PrimaryPart

1. Seleccionás el **Model**
2. Properties → **PrimaryPart** → seleccionás **HumanoidRootPart**
3. Para animarlo fijo en el lugar, dejás **solo HumanoidRootPart anclada** y desanclás las seis piezas visibles

### 6. Animar el rig

1. **Avatar → Animation Editor**
2. Seleccionás el Model
3. El editor detecta las uniones y te deja mover cada parte
4. Creás los keyframes y publicás

### 7. Problemas comunes

| Problema | Causa |
|---|---|
| Animation Editor no muestra las partes | Falta el Humanoid o Motor6D mal configurados |
| Una extremidad no se anima | Sigue anclada o su Motor6D está mal conectado |
| El Humanoid muere al probar | Revisá Torso, Head y la unión Neck |
| El brazo salta al centro del torso al conectarlo | C0/C1 en su valor default; usá RigLink (Paso 4) para conectarlo sin que se mueva |
| El brazo gira desde el medio en vez del hombro | El punto de giro no está en el hombro; ajustalo con "Manual Alignment" en RigLink |

## Ejercicio

> Consigna: Creá un rig personalizado y hacé al menos 1 animación funcional (idle, caminar o saludo).

**Pistas:**
1. Respetá los nombres y las conexiones de las tablas para este rig personalizado
2. Usá el plugin **RigLink** para conectar las partes sin que salten de lugar
3. Si el punto de giro no queda en el hombro, usá "Manual Alignment" para ajustarlo a mano
4. Si el Animation Editor no muestra las partes, revisá que el Humanoid esté agregado
