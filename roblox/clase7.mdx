# Clase 7: Bloque de la muerte y bloque de supersalto 💀🦘

Accedemos a las propiedades del Humanoid para crear bloques que afectan al jugador.

## Objetivos

- Conocer las propiedades principales del Humanoid
- Programar un bloque que quita toda la vida
- Programar un bloque que aumenta el salto temporalmente

## Contenido

### 1. Conocer el Humanoid

Cada personaje tiene un objeto **Humanoid** con propiedades que podés modificar desde código.

| Propiedad | Qué controla | Valor default |
|---|---|---|
| `Health` | Salud actual | 100 |
| `WalkSpeed` | Velocidad de caminar | 16 |
| `JumpHeight` | Altura del salto | 7.2 |
| `Jump` | Hace saltar al personaje | false |

### 2. Crear el bloque de la muerte

1. Insertás una Part en el Workspace y le agregás un **Script**
2. El código accede al personaje que tocó el bloque y le pone la salud en 0

```lua
local bloque = script.Parent

bloque.Touched:Connect(function(mano)
    local personaje = mano.Parent
    local humanoid = personaje.Humanoid
    humanoid.Health = 0   -- pone la salud en 0
end)
```

### 3. Crear el bloque de supersalto

```lua
local bloque = script.Parent

bloque.Touched:Connect(function(mano)
    local personaje = mano.Parent
    local humanoid = personaje.Humanoid
    humanoid.Jump = true        -- hace saltar
    humanoid.JumpHeight = 100   -- aumenta la altura
    wait(0.5)
    humanoid.JumpHeight = 7.2   -- vuelve al valor normal
end)
```

### 4. Dónde va el script

El script va **dentro del bloque** (Part) en el Workspace:

```
Workspace
  └── Bloque (Part)
        └── Script
```

2. Probá también armar el bloque de supersalto como práctica extra
