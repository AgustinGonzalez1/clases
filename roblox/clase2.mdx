# Clase 2: El Arte de Crear Paisajes 🏞️

Esculpimos terrenos, montañas y ríos, y ajustamos las luces y el cielo de nuestro mundo.

## Objetivos

- Usar el Terrain Editor para generar y modelar terreno
- Crear colinas y un lago
- Ajustar la iluminación y el cielo del mapa

## Contenido

### 1. Abrir el Terrain Editor

Se abre desde **Home → Editor → Terrain Editor**. Es la herramienta principal para crear paisajes naturales.

### 2. Generar una base con Generate

1. Dentro del Terrain Editor → **Generate**
2. Configurás **Biome** (Plains, Mountains, Arctic, etc.) y **Size**
3. Genera un terreno automático como punto de partida

### 3. Modelar el terreno con Add, Subtract y Smooth

| Herramienta | Qué hace |
|---|---|
| **Add** | Agrega tierra donde pintás con el mouse |
| **Subtract** | Excava el terreno, hace hoyos o depresiones |
| **Smooth** | Suaviza los bordes bruscos |

**Ejemplo — hacer una colina:**
1. **Add** con material **Grass**, pintás hacia arriba para levantar tierra
2. **Smooth** para suavizar los bordes

**Ejemplo — hacer un lago:**
1. **Subtract** para hacer una depresión en el terreno
2. **Add** con material **Water** para rellenarla

### 4. Aplicar materiales con Paint

**Paint** cambia el material del terreno sin modificar su forma.

| Material | Para qué se usa |
|---|---|
| **Grass** | Llanuras y colinas |
| **Rock** | Montañas y acantilados |
| **Sand** | Playas y desiertos |
| **Snow** | Cimas nevadas |

### 5. Ajustar luces y cielo

Se configuran desde el objeto **Lighting** en el Explorer:

| Propiedad | Qué controla |
|---|---|
| **Ambient** | Color de luz general del mundo |
| **Brightness** | Intensidad de la luz |
| **TimeOfDay** | Hora del día (formato HH:MM:SS) |

Para cambiar el cielo:
1. Seleccionás **Lighting** → Insert Object → **Sky**
2. Podés cambiar las texturas de cada cara del skybox

**Ejemplo:** probá `TimeOfDay = 06:00:00` para un amanecer.

## Ejercicio

> Consigna: Diseñá un mapa natural con al menos 2 colinas y un lago.

**Pistas:**
1. Usá `Smooth` después de `Add` para que las colinas no queden con picos irregulares
2. Combiná `Subtract` + `Water` para el lago
3. Probá distintos materiales en cada zona del mapa
