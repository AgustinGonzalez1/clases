# Clase 14: Animaciones con Código 🎬

---

## Paso 1: El script principal (tecla F)

Va en **StarterPlayer → StarterCharacterScripts**.

```lua
local personaje = script.Parent
local humanoid = personaje:WaitForChild("Humanoid")
local animator = humanoid:WaitForChild("Animator")

local animacion = Instance.new("Animation")
animacion.AnimationId = "rbxassetid://TU_ID_ACA"
local track = animator:LoadAnimation(animacion)

local UIS = game:GetService("UserInputService")

UIS.InputBegan:Connect(function(input)
    if input.KeyCode == Enum.KeyCode.F then
        track:Play()
    end
end)
```

---

## Paso 2 (extra): Animación con el Tool

1. Copiás el Tool y lo pegás **dentro del rig** en el Workspace
2. Abrís el Animation Editor con el rig + Tool y animás el ataque
3. Publicás la animación

```lua
-- agregado al mismo script
personaje.ChildAdded:Connect(function(child)
    if child:IsA("Tool") then
        track.Priority = Enum.AnimationPriority.Action
        child.Activated:Connect(function()
            track:Play()
        end)
    end
end)
```

## Misión

> Reproducir una animación al presionar una tecla.
