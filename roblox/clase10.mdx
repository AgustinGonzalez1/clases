# Clase 10: ¡Hola, Amigo NPC! 👋

## Paso 1: Crear el NPC

Reutilizás el rig de la Clase 5, o armás uno nuevo con Humanoid. Lo nombrás `rig` y lo ubicás en el Workspace.

---

## Paso 2: Agregar el BillboardGui

1. Click derecho sobre la **Head** del NPC → Insert Object → **BillboardGui**
2. Dentro del BillboardGui → Insert Object → **TextLabel**

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| BillboardGui → **StudsOffset** | `0, 2, 0` | Sube el texto sobre la cabeza |
| TextLabel → **TextScaled** | `true` | El texto se ajusta al tamaño |
| TextLabel → **BackgroundTransparency** | `1` | Fondo transparente |

```
Workspace
  └── rig (Model)
        └── Head
              └── BillboardGui
                    └── TextLabel
```

---

## Paso 3: El LocalScript

Va en **StarterPlayer → StarterPlayerScripts**.

```lua
local npc = workspace:WaitForChild("rig")           -- espera a que el NPC aparezca
local cabeza = npc:WaitForChild("Head")              -- espera a que la cabeza este lista
local texto = cabeza.BillboardGui.TextLabel          -- texto que flota sobre la cabeza

local jugador = game.Players.LocalPlayer             -- el jugador que ejecuta este script
local personaje = jugador.Character                  -- personaje fisico del jugador
local rootPart = personaje.HumanoidRootPart          -- parte central del jugador

game:GetService("RunService").Heartbeat:Connect(function()  -- corre 60 veces por segundo
    local distancia = (cabeza.Position - rootPart.Position).Magnitude  -- distancia real

    if distancia < 10 then
        texto.Text = "¡Hola! Estás muy cerca 👋"
    elseif distancia < 20 then
        texto.Text = "Te veo por ahí..."
    else
        texto.Text = ""
    end
end)
```

## Misión

> NPC con diálogos distintos según la cercanía del jugador.
