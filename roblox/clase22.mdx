# Clase 22: Enemigos con IA Básica 🤖

Programamos un enemigo que patrulla entre puntos del mapa y persigue al jugador cuando se acerca lo suficiente.

## Objetivos

- Construir un enemigo con Humanoid y puntos de patrulla
- Detectar al jugador por distancia con `Magnitude`
- Manejar estados (patrullando / persiguiendo) sin que la detección se retrase
- Perseguir de forma fluida con `Move`

## Contenido

### 1. Crear el enemigo

1. Armás un modelo simple con Parts o reutilizás el rig de la Clase 5
2. Le agregás un **Humanoid**
3. Asignás el **PrimaryPart** del modelo al **HumanoidRootPart** (obligatorio, sin esto no se mueve)
4. Lo renombrás `Enemigo` y lo ubicás en el Workspace

> ⚠️ Este enemigo no va a tener animación de caminar hasta que le agregues una. Sin animación se desliza por el piso en vez de mover las piernas. Lo resolvemos en el Extra del paso 13.

### 2. Crear los puntos de patrulla

1. Insertás 3 Parts en el Workspace
2. Las renombrás `Punto1`, `Punto2`, `Punto3`
3. Las ubicás en distintos lugares del mapa
4. Las hacés invisibles: **Transparency** en `1` y **CanCollide** en `false`
5. **Anchored** en `true`, para que no se caigan
6. Click derecho en el modelo `Enemigo` → Insert Object → **Script**

```
Workspace
  ├── Enemigo (Model)
  │     ├── Humanoid
  │     ├── HumanoidRootPart
  │     └── Script
  ├── Punto1 (Part invisible)
  ├── Punto2 (Part invisible)
  └── Punto3 (Part invisible)
```

### 3. Cómo funciona la IA: los estados

El enemigo siempre está en uno de dos **estados**, y según cuál sea, hace una cosa u otra:

| Estado | Qué hace | Cuándo cambia |
|---|---|---|
| `"patrullando"` | Camina de punto en punto | Cuando un jugador se acerca a menos de 15 studs |
| `"persiguiendo"` | Camina hacia el jugador | Nunca, en la versión básica (lo resolvemos en el Extra del paso 14) |

El script tiene dos partes trabajando al mismo tiempo:
- Una que **vigila** constantemente si hay un jugador cerca (y cambia el estado)
- Otra que **actúa** según el estado actual (patrullar o perseguir)

### 4. Servicios, configuración y referencias

```lua
-- Servicios
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores
local RunService = game:GetService("RunService")    -- para revisar algo en cada frame

-- Configuracion
local RANGO_DETECCION = 15                          -- a cuantos studs detecta al jugador
local VELOCIDAD_PATRULLA = 8                        -- velocidad mientras patrulla
local VELOCIDAD_PERSECUCION = 12                    -- velocidad mientras persigue
local ESPERA_EN_PUNTO = 1                           -- segundos que se queda en cada punto
local TIEMPO_MAXIMO_POR_PUNTO = 8                   -- si no llega en este tiempo, sigue al proximo

-- Referencias
local enemigo = script.Parent                       -- el modelo que contiene este script
local humanoid = enemigo:WaitForChild("Humanoid")   -- controla el movimiento del enemigo
local rootPart = enemigo:WaitForChild("HumanoidRootPart")  -- la parte central del enemigo

local puntos = {                                    -- tabla con las posiciones de patrulla
    workspace:WaitForChild("Punto1").Position,
    workspace:WaitForChild("Punto2").Position,
    workspace:WaitForChild("Punto3").Position,
}
```

- **Configuración** junta todos los números que se pueden ajustar. Si el enemigo es muy rápido o detecta muy lejos, se cambia acá sin buscar por el código
- `script.Parent` es directamente el modelo `Enemigo`, porque el script está adentro
- `WaitForChild` evita errores si el script corre antes de que las partes terminen de cargar
- `puntos` es una tabla (Clase 21) con las 3 posiciones, para recorrerlas con un `for`

### 5. Variables de estado

```lua
-- Estado
local estado = "patrullando"                        -- que esta haciendo el enemigo ahora
local jugadorDetectado = nil                        -- a quien persigue (al principio, a nadie)
```

### 6. Detectar al jugador cerca

```lua
local function detectarJugador()
    if estado == "persiguiendo" then return end     -- si ya persigue a alguien, no busca otro

    for _, jugador in ipairs(Players:GetPlayers()) do  -- recorre todos los jugadores
        local personaje = jugador.Character         -- su personaje
        local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")  -- su parte central, si existe

        if rootJugador then                         -- solo si el personaje esta cargado
            local distancia = (rootPart.Position - rootJugador.Position).Magnitude  -- distancia real
            if distancia < RANGO_DETECCION then     -- si esta cerca
                jugadorDetectado = jugador          -- lo guarda
                estado = "persiguiendo"             -- cambia el estado
            end
        end
    end
end
```

- `Magnitude` calcula la distancia real entre dos posiciones, como en la Clase 10
- `personaje and personaje:FindFirstChild(...)` revisa dos cosas: que el personaje exista **y** que tenga su HumanoidRootPart. Si un jugador está reapareciendo, todavía no la tiene, y sin este control el script tiraría error y se rompería
- Esta función **solo cambia el estado**, no mueve al enemigo. Moverlo es trabajo de otras funciones

### 7. Caminar hasta un punto sin quedarse trabado

```lua
local function caminarHasta(punto)
    humanoid:MoveTo(punto)                          -- empieza a caminar hacia el punto

    local llego = false                             -- todavia no llego
    local conexion = humanoid.MoveToFinished:Connect(function()
        llego = true                                -- se marca cuando llega
    end)

    local tiempo = 0                                -- cuanto tiempo lleva caminando
    while not llego and estado == "patrullando" and tiempo < TIEMPO_MAXIMO_POR_PUNTO do
        tiempo = tiempo + task.wait(0.1)            -- espera un poco y suma el tiempo que espero
    end

    conexion:Disconnect()                           -- deja de escuchar MoveToFinished
end
```

- El `while` espera hasta que pase **lo primero** de estas tres cosas: que llegue, que cambie el estado, o que pasen 8 segundos
- `task.wait(0.1)` espera una décima de segundo y además **devuelve cuánto esperó de verdad**, por eso podemos sumarlo directo a `tiempo`
- Revisar el estado cada 0.1 segundos es la clave: si aparece un jugador, el enemigo deja de patrullar casi al instante, sin esperar a llegar al punto

> 💡 **¿Por qué no usar `MoveToFinished:Wait()`?** Porque frena el script hasta que el enemigo llega al punto. Si un jugador aparece en el camino, el enemigo lo ignora hasta llegar. Ese era el bug que tenía la primera versión de esta clase.

### 8. Patrullar

```lua
local function patrullar()
    humanoid.WalkSpeed = VELOCIDAD_PATRULLA         -- camina tranquilo

    for _, punto in ipairs(puntos) do               -- recorre los puntos en orden
        if estado ~= "patrullando" then return end  -- si detecto a alguien, corta la patrulla
        caminarHasta(punto)                         -- camina hasta este punto

        if estado ~= "patrullando" then return end  -- si detecto a alguien en el camino, corta
        task.wait(ESPERA_EN_PUNTO)                  -- se queda un momento en el punto
    end
end
```

- `return` corta la función en el momento: si el estado cambió, no sigue al próximo punto
- Se revisa el estado **antes y después** de caminar, para no quedarse esperando en un punto si ya tiene que perseguir

### 9. Perseguir

```lua
local function perseguir()
    humanoid.WalkSpeed = VELOCIDAD_PERSECUCION      -- camina mas rapido

    local personaje = jugadorDetectado.Character    -- el personaje del jugador detectado
    local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")  -- su parte central

    if rootJugador then                             -- si el jugador sigue disponible
        local direccion = (rootJugador.Position - rootPart.Position).Unit  -- direccion hacia el jugador
        humanoid:Move(direccion)                    -- camina en esa direccion
    else
        humanoid:Move(Vector3.zero)                 -- si no esta, se frena
    end
end
```

- `.Unit` convierte el vector en uno de **largo 1**, quedándose solo con la dirección
- `humanoid:Move(direccion)` es lo mismo que pasa cuando el jugador aprieta WASD: movimiento fluido, sin pausas al girar
- `Move` **mantiene** la última dirección hasta que le digas otra. Por eso, si el jugador se fue o está reapareciendo, lo frenamos con `Vector3.zero` (sin dirección)

> ⚠️ Acá se usa `Move()` y no `MoveTo()`. `MoveTo` espera una **posición** a la que ir, y `direccion` es solo hacia dónde caminar.

### 10. El inicio: vigilar y actuar

```lua
-- Inicio
RunService.Heartbeat:Connect(detectarJugador)       -- vigila en cada frame si hay alguien cerca

while true do                                       -- se repite para siempre
    if estado == "patrullando" then
        patrullar()                                 -- recorre los puntos
    else
        perseguir()                                 -- camina hacia el jugador
    end
    task.wait()                                     -- espera un frame antes de repetir
end
```

- `Heartbeat` corre `detectarJugador` en cada frame, **al mismo tiempo** que el `while`. Por eso la detección nunca se retrasa
- El `while true do` es el que **actúa**: según el estado, patrulla o persigue
- `task.wait()` sin número espera un frame. Sin esa línea, el `while` se repetiría infinitas veces por segundo y trabaría el juego

### 12. Limitaciones y problemas comunes

| Problema | Causa | Solución |
|---|---|---|
| El enemigo no se mueve | Falta asignar el **PrimaryPart** o tiene partes con **Anchored** en `true` | Asignar PrimaryPart y desanclar todas las partes del enemigo |
| Se desliza sin mover las piernas | No tiene animación de caminar | Ver el Extra del paso 13 |
| No esquiva paredes | `MoveTo` y `Move` van en línea recta | Es una limitación de esta IA básica |
| Una vez que persigue, nunca vuelve a patrullar | En esta versión, el estado no vuelve atrás | Ver el Extra del paso 14 |
| Persigue siempre al primero que vio | No vuelve a buscar mientras persigue | Ver el Extra del paso 15 |
| Error `Punto1 is not a valid member` | Los puntos tienen otro nombre | Tienen que llamarse exactamente `Punto1`, `Punto2`, `Punto3` |

### 13. Extra: animaciones y ataque

Si querés que camine moviendo las piernas y que ataque al alcanzarte, combinamos lo visto en las Clases 4, 7 y 14.

**1. Agregá en Configuración:**

```lua
local ID_CAMINAR = "rbxassetid://TU_ID_CAMINAR"     -- tu animacion de caminar (Clase 4)
local ID_ATAQUE = "rbxassetid://TU_ID_ATAQUE"       -- tu animacion de ataque
local RANGO_ATAQUE = 5                              -- a cuantos studs ataca
local DANIO = 20                                    -- cuanta vida quita cada golpe
```

**2. Agregá en Referencias:**

```lua
local animator = humanoid:WaitForChild("Animator")  -- reproduce animaciones en el enemigo
```

**3. Agregá estas funciones antes de `perseguir`:**

```lua
local function cargarAnimacion(id)
    local animacion = Instance.new("Animation")     -- crea el objeto Animation
    animacion.AnimationId = id                      -- le pone el ID
    return animator:LoadAnimation(animacion)        -- la carga y devuelve el track listo para usar
end

local trackCaminar = cargarAnimacion(ID_CAMINAR)    -- animacion de caminar
trackCaminar.Looped = true                          -- que se repita mientras camina
local trackAtaque = cargarAnimacion(ID_ATAQUE)      -- animacion de ataque

local function alCorrer(velocidad)
    if velocidad > 0.1 and not trackCaminar.IsPlaying then  -- si se mueve y la animacion no corre
        trackCaminar:Play()                         -- arranca la animacion
    elseif velocidad <= 0.1 and trackCaminar.IsPlaying then -- si esta quieto y la animacion corre
        trackCaminar:Stop()                         -- la frena
    end
end

local function atacar(personaje)
    trackAtaque:Play()                              -- reproduce el golpe
    local humanoidJugador = personaje:FindFirstChild("Humanoid")  -- busca el Humanoid del jugador
    if humanoidJugador then
        humanoidJugador:TakeDamage(DANIO)           -- le quita vida
    end
    task.wait(1)                                    -- espera antes de poder volver a atacar
end
```

**4. Reemplazá la función `perseguir` por esta:**

```lua
local function perseguir()
    humanoid.WalkSpeed = VELOCIDAD_PERSECUCION      -- camina mas rapido

    local personaje = jugadorDetectado.Character    -- el personaje del jugador detectado
    local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")  -- su parte central

    if not rootJugador then                         -- si el jugador no esta disponible
        humanoid:Move(Vector3.zero)                 -- se frena
        return
    end

    local distancia = (rootJugador.Position - rootPart.Position).Magnitude  -- distancia al jugador

    if distancia < RANGO_ATAQUE then                -- si esta al alcance
        humanoid:Move(Vector3.zero)                 -- se frena para pegar
        atacar(personaje)                           -- ataca
    else
        humanoid:Move((rootJugador.Position - rootPart.Position).Unit)  -- sigue persiguiendo
    end
end
```

**5. Agregá en Inicio, antes del `while`:**

```lua
humanoid.Running:Connect(alCorrer)                  -- avisa cada vez que cambia la velocidad del enemigo
```

- `humanoid.Running` se dispara cuando el enemigo empieza a moverse, cambia de velocidad o se frena. Así la animación de caminar suena **solo** cuando camina, y no mientras ataca
- `TakeDamage` quita vida igual que restar `Health`, pero **respeta los escudos** (ForceField): si el jugador acaba de reaparecer con escudo, no le hace daño. Es la forma recomendada de hacer daño
- `return animator:LoadAnimation(...)` hace que la función **devuelva** el resultado, así se puede guardar en una variable

> ⚠️ Las animaciones tienen que estar publicadas por **la misma cuenta** (o el mismo grupo) que es dueña del juego. Si no, no se reproducen y no aparece ningún error claro.

### 14. Extra: dejar de perseguir si el jugador se aleja

Con la versión básica, una vez que el enemigo persigue, nunca vuelve a patrullar. Para que abandone la persecución si el jugador se aleja, usamos un segundo rango, más grande que el de detección.

**1. Agregá en Configuración:**

```lua
local RANGO_PERDIDA = 25                            -- a esta distancia deja de perseguir
```

**2. Reemplazá la función `detectarJugador` por esta:**

```lua
local function detectarJugador()
    if estado == "persiguiendo" then                -- si ya esta persiguiendo
        local personaje = jugadorDetectado.Character
        local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")

        if not rootJugador or (rootJugador.Position - rootPart.Position).Magnitude > RANGO_PERDIDA then
            estado = "patrullando"                  -- vuelve a patrullar
            jugadorDetectado = nil                  -- ya no persigue a nadie
            humanoid:Move(Vector3.zero)             -- frena la persecucion
        end
        return                                      -- mientras persigue, no busca a otro
    end

    for _, jugador in ipairs(Players:GetPlayers()) do  -- recorre todos los jugadores
        local personaje = jugador.Character
        local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")

        if rootJugador then
            local distancia = (rootPart.Position - rootJugador.Position).Magnitude
            if distancia < RANGO_DETECCION then
                jugadorDetectado = jugador
                estado = "persiguiendo"
            end
        end
    end
end
```

- Si el jugador se aleja más de 25 studs, se va del juego o está reapareciendo, el enemigo vuelve a patrullar
- Se usan **dos rangos distintos** (15 para empezar, 25 para abandonar) a propósito: si fuera el mismo número, con el jugador parado justo en el borde, el enemigo cambiaría de estado todo el tiempo

### 15. Extra: perseguir siempre al jugador más cercano

Con dos jugadores cerca, el enemigo persigue al primero que vio aunque el otro esté más cerca. Para que elija siempre al más cercano, buscamos al de **menor distancia** en cada frame.

**Reemplazá la función `detectarJugador` por estas dos** (incluye también el Extra del paso 14):

```lua
local function buscarMasCercano()
    local masCercano = nil                          -- todavia no encontramos a nadie
    local menorDistancia = math.huge                -- arranca con un numero enorme

    for _, jugador in ipairs(Players:GetPlayers()) do  -- recorre todos los jugadores
        local personaje = jugador.Character
        local rootJugador = personaje and personaje:FindFirstChild("HumanoidRootPart")

        if rootJugador then
            local distancia = (rootPart.Position - rootJugador.Position).Magnitude
            if distancia < menorDistancia then      -- si esta mas cerca que el mejor hasta ahora
                menorDistancia = distancia          -- guarda la nueva distancia minima
                masCercano = jugador                -- y a ese jugador
            end
        end
    end

    return masCercano, menorDistancia               -- devuelve los dos datos
end

local function detectarJugador()
    local jugador, distancia = buscarMasCercano()   -- el mas cercano y a que distancia esta

    if jugador and distancia < RANGO_DETECCION then -- si hay alguien dentro del rango
        jugadorDetectado = jugador                  -- persigue al mas cercano
        estado = "persiguiendo"
    elseif estado == "persiguiendo" and (not jugador or distancia > RANGO_PERDIDA) then
        estado = "patrullando"                      -- si se alejaron todos, vuelve a patrullar
        jugadorDetectado = nil
        humanoid:Move(Vector3.zero)
    end
end
```

- `math.huge` es un número infinitamente grande. Se usa como punto de partida para que la primera distancia que encontremos siempre sea menor
- Una función puede **devolver dos valores** separados por coma, y se reciben igual: `local jugador, distancia = buscarMasCercano()`
- En cada frame se vuelve a buscar al más cercano, así si dos jugadores se acercan, el enemigo cambia de objetivo hacia el que esté más cerca
