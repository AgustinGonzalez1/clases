# Clase 28: Tablas de Puntos (Leaderboards) 🏆

Armamos la tabla de arriba a la derecha: los puntos suben al juntar monedas y se cuentan las muertes.

## Objetivos

- Crear un leaderboard con la carpeta `leaderstats`
- Sumar puntos desde el servidor al tocar monedas
- Contar las muertes con `Humanoid.Died`

## Contenido

### 🏆 Parte 1: La tabla

### Paso 1: Crear el script

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `Leaderboard`.

Va en el **servidor** para que los puntos sean reales para todos: si se sumaran desde un LocalScript, solo los vería ese jugador.

> 📝 **Qué es un leaderboard:** la tabla de arriba a la derecha con los puntos de cada jugador. Roblox la dibuja solo si el jugador tiene una carpeta llamada `leaderstats`; cada valor que pongas adentro es una columna.

### Paso 2: El código de la tabla

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local function crearTabla(jugador)
    local leaderstats = Instance.new("Folder")      -- crea la carpeta de la tabla
    leaderstats.Name = "leaderstats"                -- con este nombre exacto, Roblox la muestra

    local puntos = Instance.new("IntValue")         -- crea la columna de puntos
    puntos.Name = "Puntos"                          -- el nombre que se ve en la tabla
    puntos.Value = 0                                -- arranca en 0
    puntos.Parent = leaderstats                     -- la mete en la carpeta

    local muertes = Instance.new("IntValue")        -- crea la columna de muertes
    muertes.Name = "Muertes"
    muertes.Value = 0
    muertes.Parent = leaderstats

    leaderstats.Parent = jugador                    -- le pone la carpeta al jugador
end

Players.PlayerAdded:Connect(crearTabla)             -- cada vez que entra un jugador, le crea su tabla
```

- Si el jugador tiene una carpeta llamada `leaderstats`, Roblox arma la tabla solo, con una columna por cada valor de adentro
- `IntValue` guarda un número entero (también existen `NumberValue` para decimales y `StringValue` para texto)
- `PlayerAdded` le crea a **cada jugador** su propia tabla
- `Instance.new` crea objetos desde el código: primero la carpeta, después cada columna, y al final se la pone al jugador (`leaderstats.Parent = jugador`)

> ⚠️ Tiene que llamarse **exactamente `leaderstats`**, en minúscula. Con una letra distinta la tabla no aparece y no sale ningún error.

> ⚠️ El número se cambia siempre con **`.Value`**. `puntos = puntos + 5` tira error.

```lua
puntos.Value = 10                                   -- pone 10 puntos
puntos.Value = puntos.Value + 5                     -- le suma 5 a lo que tenia
```

### 🪙 Parte 2: Las monedas

### Paso 1: Crear la carpeta

Click derecho en **Workspace** → Insert Object (**Insertar objeto**) → **Folder**, la renombrás `Monedas`.

> 📝 **Qué es una Folder:** una carpeta para ordenar objetos. No se ve en el juego; el script la recorre para encontrar todas las monedas juntas.

### Paso 2: Crear la moneda

Click derecho en `Monedas` → Insert Object (**Insertar objeto**) → **Part**, la renombrás `Moneda`.

En Propiedades, Studio agrupa todo por secciones. Cambiás las marcadas con ✏️; las otras las nombramos porque las vas a ver y el script usa algunas.

**Aspecto**

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Color** ✏️ | `255, 200, 0` | Amarillo, para que parezca de oro |
| **Material** ✏️ | `Neon` | La hace brillar |
| **Transparency** | `0` | Cuánto se ve a través: `0` sólida, `1` invisible. El script la pone en `1` para esconder la moneda |
| **CastShadow** | ✔ | Si tira sombra |

### Paso 4: El script Monedas

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `Monedas`:

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local PUNTOS_POR_MONEDA = 10                        -- cuantos puntos da cada moneda
local TIEMPO_REAPARICION = 5                        -- segundos que tarda en volver a aparecer

local carpetaMonedas = workspace:WaitForChild("Monedas")  -- la carpeta con todas las monedas

local function alTocarMoneda(moneda, parteQueToco)
    local jugador = Players:GetPlayerFromCharacter(parteQueToco.Parent)  -- busca que jugador la toco
    if not jugador or not moneda.CanTouch then return end  -- si no es un jugador o ya la agarraron, no hace nada

    local puntos = jugador.leaderstats.Puntos       -- la columna de puntos de ese jugador
    puntos.Value = puntos.Value + PUNTOS_POR_MONEDA -- le suma los puntos

    moneda.Transparency = 1                         -- la hace invisible
    moneda.CanTouch = false                         -- y que no se pueda volver a tocar
    task.wait(TIEMPO_REAPARICION)                   -- espera unos segundos
    moneda.Transparency = 0                         -- vuelve a aparecer
    moneda.CanTouch = true                          -- y se puede agarrar de nuevo
end

for _, moneda in carpetaMonedas:GetChildren() do    -- recorre todas las monedas de la carpeta
    moneda.Touched:Connect(function(parteQueToco)   -- cuando alguien toca esta moneda
        alTocarMoneda(moneda, parteQueToco)
    end)
end
```

- `Touched` avisa cuando algo toca la moneda; el `for` conecta ese aviso en cada moneda de la carpeta
- `GetPlayerFromCharacter` dice qué jugador tocó la moneda (o `nil` si no fue un jugador)
- `jugador.leaderstats.Puntos` baja por las carpetas igual que en el Explorer
- El control de `CanTouch` evita que una moneda dé puntos varias veces, porque `Touched` se dispara por cada parte del cuerpo
- La moneda **se oculta** y vuelve a los 5 segundos (Clase 24)

**Probalo:** Play y tocá una moneda: desaparece y sumás 10 puntos.

### 💀 Parte 3: Las muertes

### Paso 1: Contar las muertes

En el script `Leaderboard`, agregás esto **adentro de `crearTabla`**, antes del `end` (como en la Clase 27):

```lua
    jugador.CharacterAdded:Connect(function(personaje)  -- cada vez que aparece o reaparece
        local humanoid = personaje:WaitForChild("Humanoid")  -- espera a que el Humanoid este listo
        humanoid.Died:Connect(function()            -- cuando este personaje muere
            muertes.Value = muertes.Value + 1       -- le suma una muerte
        end)
    end)
```

- `humanoid.Died` avisa cuando el personaje muere, y ahí se suma 1 a `Muertes`
- Cada vez que reaparecés, Roblox crea un **Humanoid nuevo**: por eso `CharacterAdded` vuelve a conectar el `Died`

Así queda el script completo:

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local function crearTabla(jugador)
    local leaderstats = Instance.new("Folder")      -- crea la carpeta de la tabla
    leaderstats.Name = "leaderstats"                -- con este nombre exacto, Roblox la muestra

    local puntos = Instance.new("IntValue")         -- crea la columna de puntos
    puntos.Name = "Puntos"                          -- el nombre que se ve en la tabla
    puntos.Value = 0                                -- arranca en 0
    puntos.Parent = leaderstats                     -- la mete en la carpeta

    local muertes = Instance.new("IntValue")        -- crea la columna de muertes
    muertes.Name = "Muertes"
    muertes.Value = 0
    muertes.Parent = leaderstats

    leaderstats.Parent = jugador                    -- le pone la carpeta al jugador

    jugador.CharacterAdded:Connect(function(personaje)  -- cada vez que aparece o reaparece
        local humanoid = personaje:WaitForChild("Humanoid")  -- espera a que el Humanoid este listo
        humanoid.Died:Connect(function()            -- cuando este personaje muere
            muertes.Value = muertes.Value + 1       -- le suma una muerte
        end)
    end)
end

Players.PlayerAdded:Connect(crearTabla)             -- cada vez que entra un jugador, le crea su tabla
```

### Paso 2: El bloque de la muerte

Click derecho en **Workspace** → Insert Object (**Insertar objeto**) → **Part**, la renombrás `BloqueMuerte`:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `10, 1, 6` | Una losa ancha y baja, fácil de pisar |
| **Color** | Rojo | Que se note que es peligroso |
| **Material** | `Neon` | Que brille |
| **Anchored** | `true` | Que no se mueva |

Adentro, un **Script** (el de la Clase 7). Cuando lo toca un personaje, le pone la vida (`Health`) en 0:

```lua
local bloque = script.Parent                        -- el bloque que contiene este script

bloque.Touched:Connect(function(parteQueToco)       -- cuando algo toca el bloque
    local humanoid = parteQueToco.Parent:FindFirstChild("Humanoid")  -- busca si es un personaje
    if humanoid then
        humanoid.Health = 0                         -- lo mata
    end
end)
```

### Problemas comunes

| Problema | Solución |
|---|---|
| La tabla no aparece | La carpeta tiene que llamarse `leaderstats`, en minúscula. Si estás jugando, apretá **Tab** |
| Error `attempt to perform arithmetic` | Usá `puntos.Value = puntos.Value + 10`, no `puntos = puntos + 10` |
| Una moneda no da puntos | Tiene que estar adentro de la carpeta `Monedas` |
| Las monedas me frenan | **CanCollide** en `false` |
| Las muertes no suben | Falta el `CharacterAdded` del Paso 1 de la Parte 3 |

### Extras

**Una columna de rango:** dentro de `crearTabla`, antes de `leaderstats.Parent = jugador`:

```lua
    local rango = Instance.new("StringValue")       -- columna de texto
    rango.Name = "Rango"
    rango.Value = "Novato"                          -- todos arrancan como Novato
    rango.Parent = leaderstats

    puntos.Changed:Connect(function(nuevosPuntos)   -- cada vez que cambian los puntos
        if nuevosPuntos >= 100 then
            rango.Value = "Leyenda"
        elseif nuevosPuntos >= 50 then
            rango.Value = "Experto"
        else
            rango.Value = "Novato"
        end
    end)
```

- `StringValue` guarda texto; `.Changed` avisa cada vez que cambia el valor

**Los puntos se pierden al salir:** se guardan con DataStore en la Clase 31.
