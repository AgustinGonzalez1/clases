# Tu Primera Arma: La Espada ⚔️

---

## Paso 1: Construir las 3 partes

| Parte | Nombre en Studio |
|---|---|
| Mango | `Handle` |
| Guardia | `Guardia` |
| Hoja | `Hoja` |

> ⚠️ El nombre `Handle` es obligatorio, Roblox lo usa como punto de agarre.

---

## Paso 2: Crear el Tool en el Workspace

1. Click derecho sobre Workspace → Insert Object → **Tool**
2. Arrastrás las 3 Parts dentro del Tool

```
Workspace
  └── Tool
        ├── Handle
        ├── Guardia
        └── Hoja
```

---

## Paso 3: Unir con WeldConstraint

1. **Handle** → Insert Object → **WeldConstraint** → `Part0=Handle` / `Part1=Guardia`
2. **Guardia** → Insert Object → **WeldConstraint** → `Part0=Guardia` / `Part1=Hoja`

```
Workspace
  └── Tool
        ├── Handle
        │     └── WeldConstraint (Part0=Handle / Part1=Guardia)
        ├── Guardia
        │     └── WeldConstraint (Part0=Guardia / Part1=Hoja)
        └── Hoja
```

---

## Paso 4: Ajustar el Grip

En Properties del Tool:

| Propiedad | Valor recomendado |
|---|---|
| **Grip → Orientation** | `0, 0, -90` |

Ajustás hasta que se vea natural en la mano del personaje.

---

## Misión

> Diseñar tu espada con estilo propio.
