# Clase 13: Tu Primer Auto 🚗

---

## Paso 1: Construir las partes sin nombrarlas todavía

1. Insertás el **Chasis** (Part rectangular)
2. Insertás 4 Parts cilíndricas para las ruedas, sin nombrarlas aún
3. Las rotás **Orientation → 0, 0, 90** para que queden horizontales
4. Las ubicás en las 4 esquinas del Chasis

> ⚠️ **Anchored = true** en todas mientras construís.

---

## Paso 2: Agregar el VehicleSeat para definir la orientación

1. Insert Object → **VehicleSeat**, lo ubicás encima del Chasis
2. El **frente** del VehicleSeat (la flecha que se ve al seleccionarlo) define hacia dónde "mira" el auto

> 💡 Con el VehicleSeat ya orientado, ahora es fácil saber cuál rueda es cuál: mirando hacia adelante desde el asiento, la izquierda y derecha quedan claras.

---

## Paso 3: Recién ahora, nombrar las ruedas correctamente

Según la orientación del VehicleSeat:

| Rueda | Nombre |
|---|---|
| Adelante-derecha | `RFD` |
| Adelante-izquierda | `RFI` |
| Atrás-derecha | `RTD` |
| Atrás-izquierda | `RTI` |

---

## Paso 4: Agrupar

1. Seleccionás todo (Chasis, las 4 ruedas y el VehicleSeat) y **Group** (Ctrl+G)
2. Renombrás el Model `Autito`
3. **PrimaryPart** del Model → `Chasis`

---

## Paso 5: Crear la carpeta Uniones

Dentro de `Autito` → Insert Object → **Folder** → `Uniones`. Dentro, 4 **HingeConstraint**:

| HingeConstraint | Config |
|---|---|
| `ejeRFD`, `ejeRFI`, `ejeRTD`, `ejeRTI` | ActuatorType=Motor, MotorMaxTorque=409600, AngularVelocity=0 |

---

## Paso 6: Attachments

**En el Chasis:** `pivoteChasisRFD`, `pivoteChasisRFI`, `pivoteChasisRTD`, `pivoteChasisRTI`

**En cada rueda:** `pivoteRuedaRFD`, `pivoteRuedaRFI`, `pivoteRuedaRTD`, `pivoteRuedaRTI`

Mové cada `pivoteChasis` a la misma posición que su `pivoteRueda` correspondiente.

---

## Paso 7: Configurar los HingeConstraints

| HingeConstraint | Attachment0 | Attachment1 |
|---|---|---|
| ejeRFD | pivoteChasisRFD | pivoteRuedaRFD |
| ejeRFI | pivoteChasisRFI | pivoteRuedaRFI |
| ejeRTD | pivoteChasisRTD | pivoteRuedaRTD |
| ejeRTI | pivoteChasisRTI | pivoteRuedaRTI |

---

## Paso 8: WeldConstraint del VehicleSeat

VehicleSeat → Insert Object → **WeldConstraint** → `Part0=VehicleSeat` / `Part1=Chasis`

---

## Paso 10: El script

Va dentro del **Script** que está en VehicleSeat.

```lua
local asiento = script.Parent
local auto = asiento.Parent

local motoresDerecha = {auto.Uniones.ejeRFD, auto.Uniones.ejeRTD}
local motoresIzquierda = {auto.Uniones.ejeRFI, auto.Uniones.ejeRTI}

local VELOCIDAD_AVANCE = 50
local FUERZA_GIRO_LENTO = 40
local FUERZA_GIRO_RAPIDO = 10

local function establecerVelocidad(listaMotores, velocidad)
    for _, motor in ipairs(listaMotores) do
        motor.AngularVelocity = velocidad
    end
end

local function actualizarMotores()
    local acelerador = -asiento.ThrottleFloat
    local giro = -asiento.SteerFloat

    local factorVelocidad = math.abs(acelerador)
    local fuerzaGiro = FUERZA_GIRO_LENTO - (FUERZA_GIRO_LENTO - FUERZA_GIRO_RAPIDO) * factorVelocidad

    local velocidadBase = acelerador * VELOCIDAD_AVANCE
    local ajusteGiro = giro * fuerzaGiro
    local velocidadIzquierda = velocidadBase + ajusteGiro
    local velocidadDerecha   = velocidadBase - ajusteGiro

    establecerVelocidad(motoresIzquierda, velocidadIzquierda)
    establecerVelocidad(motoresDerecha,  velocidadDerecha)
end

asiento:GetPropertyChangedSignal("ThrottleFloat"):Connect(actualizarMotores)
asiento:GetPropertyChangedSignal("SteerFloat"):Connect(actualizarMotores)
```
