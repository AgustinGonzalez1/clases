# Clase 16: Cutscenes 2 📜

Armamos un menú principal con botones de "Jugar" y "Opciones", y le agregamos una transición animada que lo hace desaparecer suavemente al arrancar el juego.

## Objetivos

- Entender qué es una ScreenGui y para qué sirve un Frame
- Crear un menú con título y botones
- Detectar clicks con `MouseButton1Click`
- Animar la desaparición del menú con TweenService

## Contenido

### 1. Crear la ScreenGui

Una **ScreenGui** es el contenedor principal de cualquier interfaz en Roblox, vive dentro de **StarterGui** y se copia automáticamente a la pantalla de cada jugador.

1. Click derecho sobre **StarterGui** → Insert Object → **ScreenGui**
2. En Properties → **IgnoreGuiInset** → `true`

> 💡 `IgnoreGuiInset` evita que la barra superior de Roblox empuje tu menú hacia abajo al entrar al juego.

### 2. ¿Qué es un Frame?

Un **Frame** es un contenedor rectangular vacío, la pieza básica de cualquier GUI en Roblox. Por sí solo no muestra texto ni imagen, solo un rectángulo de color. Sirve para:

- **Agrupar** varios elementos (título, botones) como una sola unidad
- Poder animarlos o moverlos todos juntos moviendo el Frame
- Servir de **fondo** para el menú, separándolo visualmente del mundo 3D detrás

Se crea así:

1. Dentro de la ScreenGui → Insert Object → **Frame**

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **AnchorPoint** | `0.5, 0.5` | El punto de referencia del Frame pasa a ser su centro |
| **Position** | `{0.5, 0}, {0.5, 0}` | Junto con el AnchorPoint, centra el Frame en la pantalla |
| **Size** | `{1, 0}, {1, 0}` | El Frame ocupa el 100% del ancho y alto de la pantalla |
| **BackgroundColor3** | el color que quieras | El color de fondo del menú completo |

### 3. Crear el título y los botones

Dentro del Frame, insertás tres elementos:

| Elemento | Nombre | Text |
|---|---|---|
| TextLabel | `TextLabel` | "Mi Juego" |
| TextButton | `Jugar` | "Jugar" |
| TextButton | `Opciones` | "Opciones" |

Todos con **TextScaled = true** y **BackgroundTransparency = 1** (menos el Frame, que mantiene su color de fondo).

### 4. Detectar el click con MouseButton1Click

`MouseButton1Click` es el evento que se dispara cuando el jugador hace click izquierdo sobre un botón:

```lua
boton.MouseButton1Click:Connect(function()
    print("Se hizo click")
end)
```

### 5. El script completo

Va en un **LocalScript** dentro de la ScreenGui.

```lua
local screenGui = script.Parent                      -- la ScreenGui del menu
local frame = screenGui:WaitForChild("Frame")        -- el frame del menu
local botonJugar = frame:WaitForChild("Jugar")       -- el boton Jugar
local botonOpciones = frame:WaitForChild("Opciones") -- el boton Opciones
local titulo = frame:WaitForChild("TextLabel")       -- el TextLabel del titulo
local TweenService = game:GetService("TweenService") -- para animar la transicion

botonJugar.MouseButton1Click:Connect(function()      -- se dispara al hacer click en Jugar
    -- Crea todos los tweens al mismo tiempo
    local tweenFondo = TweenService:Create(frame, TweenInfo.new(1), {
        BackgroundTransparency = 1                   -- el fondo se hace transparente
    })
    local tweenJugar = TweenService:Create(botonJugar, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el boton Jugar desaparece
    })
    local tweenOpciones = TweenService:Create(botonOpciones, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el boton Opciones desaparece
    })
    local tweenTitulo = TweenService:Create(titulo, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el titulo desaparece
    })

    -- Arranca todos al mismo tiempo
    tweenFondo:Play()
    tweenJugar:Play()
    tweenOpciones:Play()
    tweenTitulo:Play()

    tweenTitulo.Completed:Wait()                     -- espera a que terminen
    screenGui.Enabled = false                        -- oculta toda la GUI
end)
```

### 6. Estructura en el Explorer

```
StarterGui
  └── ScreenGui  (IgnoreGuiInset = true)
        ├── LocalScript
        └── Frame
              ├── TextLabel
              ├── Jugar     (TextButton)
              └── Opciones  (TextButton)
```

## Ejercicio

> Consigna: Armá el menú principal con título, botón Jugar y botón Opciones, con la transición animada al presionar Jugar.

**Pistas:**
1. Recordá activar `IgnoreGuiInset` en la ScreenGui para que el menú no se desplace
2. El `AnchorPoint` en `0.5, 0.5` es clave para que el Frame quede centrado
3. Todos los tweens se pueden arrancar juntos con `:Play()` sin esperar entre ellos
