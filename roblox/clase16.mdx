# Clase 16: Cutscenes 2 📜

---

## Paso 1: Crear la ScreenGui

1. StarterGui → Insert Object → **ScreenGui**
2. Properties → **IgnoreGuiInset** → `true` (evita que la barra de Roblox empuje el menú hacia abajo)

---

## Paso 2: Crear el Frame

1. Dentro de la ScreenGui → Insert Object → **Frame**

| Propiedad | Valor |
|---|---|
| **AnchorPoint** | `0.5, 0.5` |
| **Position** | `{0.5, 0}, {0.5, 0}` |
| **Size** | `{1, 0}, {1, 0}` |
| **BackgroundColor3** | el color que quieras |

---

## Paso 3: Crear el título y los botones

Dentro del Frame, tres elementos:

| Elemento | Nombre | Text |
|---|---|---|
| TextLabel | `TextLabel` | "Mi Juego" |
| TextButton | `Jugar` | "Jugar" |
| TextButton | `Opciones` | "Opciones" |

Todos con **TextScaled = true** y **BackgroundTransparency = 1** (menos el Frame).

---

## Paso 4: El script

Va en un **LocalScript** dentro de la ScreenGui.

```lua
local screenGui = script.Parent                      -- la ScreenGui del menu
local frame = screenGui:WaitForChild("Frame")        -- el frame del menu
local botonJugar = frame:WaitForChild("Jugar")       -- el boton Jugar
local botonOpciones = frame:WaitForChild("Opciones") -- el boton Opciones
local titulo = frame:WaitForChild("TextLabel")       -- el TextLabel del titulo
local TweenService = game:GetService("TweenService") -- para animar la transicion

botonJugar.MouseButton1Click:Connect(function()      -- se dispara al hacer click en Jugar
    -- Crea todos los tweens al mismo tiempo
    local tweenFondo = TweenService:Create(frame, TweenInfo.new(1), {
        BackgroundTransparency = 1                   -- el fondo se hace transparente
    })
    local tweenJugar = TweenService:Create(botonJugar, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el boton Jugar desaparece
    })
    local tweenOpciones = TweenService:Create(botonOpciones, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el boton Opciones desaparece
    })
    local tweenTitulo = TweenService:Create(titulo, TweenInfo.new(1), {
        TextTransparency = 1,                        -- el titulo desaparece
    })

    -- Arranca todos al mismo tiempo
    tweenFondo:Play()
    tweenJugar:Play()
    tweenOpciones:Play()
    tweenTitulo:Play()

    tweenTitulo.Completed:Wait()                     -- espera a que terminen
    screenGui.Enabled = false                        -- oculta toda la GUI
end)
```
