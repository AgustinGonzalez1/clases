# La Pistola de Rayos 🔫

Construimos una pistola y la programamos para que dispare proyectiles visibles con un contador de disparos en pantalla.

---

## ¿Qué es tool.Activated?

`Activated` es un evento especial de los Tools que se dispara cuando el jugador hace **click izquierdo** con el Tool equipado. Es la forma de detectar que el jugador usó el arma.

```lua
tool.Activated:Connect(function()
    -- esto se ejecuta cada vez que el jugador hace click
end)
```

---

## ¿Qué es Instance.new?

`Instance.new("Part")` crea una nueva Part desde código en tiempo de ejecución. Es como insertar una Part desde Studio pero de forma programática.

```lua
local bala = Instance.new("Part")   -- crea una nueva Part
bala.Size = Vector3.new(0.3, 0.3, 0.3)
bala.Parent = workspace             -- la agrega al mundo
```

---

## ¿Qué es CFrame.LookVector?

`CFrame.LookVector` es un Vector3 que representa **hacia dónde está mirando** un objeto. En el caso de la cámara, apunta hacia donde el jugador está mirando en pantalla.

```lua
local camara = workspace.CurrentCamera
local direccion = camara.CFrame.LookVector  -- hacia donde mira la camara
```

---

## ¿Qué es Debris:AddItem?

`Debris:AddItem(objeto, tiempo)` destruye un objeto después de un tiempo determinado. Es más eficiente que usar `wait()` + `Destroy()`.

```lua
game:GetService("Debris"):AddItem(bala, 3)  -- destruye la bala en 3 segundos
```

| Parte | Nombre en Studio |
|---|---|
| Mango | `Handle` |
| Cañón | `Canon` |

Mismos pasos que la Clase 11: Tool en el Workspace, WeldConstraint para unir las partes, Grip para ajustar la orientación.

## La GUI del contador

1. Click derecho sobre **StarterGui** → Insert Object → **ScreenGui**
2. Dentro de ScreenGui → Insert Object → **TextLabel**
3. Configurás el TextLabel:
   - **Text** → `"Disparos: 0"`
   - **TextScaled** → true
   - **BackgroundTransparency** → 1

---

## El script

Va en un **LocalScript** dentro del Tool.

```lua
local tool = script.Parent                            -- el Tool (la pistola)
local jugador = game.Players.LocalPlayer              -- el jugador que ejecuta este script
local personaje = jugador.Character                   -- personaje fisico del jugador
local canon = tool:WaitForChild("Canon")              -- espera a que el Canon este listo
local TweenService = game:GetService("TweenService")  -- para animar la bala en linea recta

local gui = jugador.PlayerGui:WaitForChild("ScreenGui")  -- espera a que la GUI este lista
local texto = gui:WaitForChild("TextLabel")              -- el TextLabel del contador

local disparos = 0                                    -- contador de disparos, arranca en 0

tool.Activated:Connect(function()                     -- se dispara al hacer click con el Tool
    disparos = disparos + 1                           -- suma 1 al contador
    texto.Text = "Disparos: " .. disparos             -- ".." une el texto con el numero

    local camara = workspace.CurrentCamera            -- la camara del jugador
    local direccion = camara.CFrame.LookVector        -- direccion hacia donde mira la camara

    -- Crea el proyectil
    local bala = Instance.new("Part")                 -- crea una nueva Part desde codigo
    bala.Size = Vector3.new(0.3, 0.3, 0.3)            -- tamaño pequeño
    bala.Color = Color3.fromRGB(255, 255, 0)          -- color amarillo
    bala.Anchored = true                              -- la fija para posicionarla correctamente
    bala.CanCollide = false                           -- no colisiona con nada fisicamente
    bala.CFrame = CFrame.new(canon.Position)          -- la pone en la posicion del canon
    bala.Parent = workspace                           -- la agrega al mundo

    -- Anima la bala en linea recta hacia adelante
    local destino = canon.Position + direccion * 200  -- 200 studs hacia donde mira la camara
    local tween = TweenService:Create(bala, TweenInfo.new(1), {Position = destino})
    tween:Play()                                      -- arranca la animacion

    game:GetService("Debris"):AddItem(bala, 3)        -- destruye la bala despues de 3 segundos
end)
```
