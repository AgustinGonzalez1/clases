# Clase 12: La Pistola de Rayos 🔫

Construimos una pistola y la programamos para que dispare proyectiles visibles con un contador de disparos en pantalla.

## Objetivos

- Construir una pistola como Tool
- Crear un proyectil visual con Instance.new
- Contar disparos con una GUI

## Contenido

### 1. Las partes de la pistola

| Parte | Nombre |
|---|---|
| Mango | `Handle` |
| Cañón | `Canon` |

Mismos pasos de la Clase 11: Tool en Workspace, WeldConstraint, Grip.

### 2. La GUI del contador

1. StarterGui → Insert Object → **ScreenGui**
2. Dentro → Insert Object → **TextLabel**
   - **Text** → `"Disparos: 0"`
   - **TextScaled** → `true`
   - **BackgroundTransparency** → `1`

### 3. El script

Va en un **LocalScript** dentro del Tool.

```lua
local tool = script.Parent                            -- el Tool (la pistola)
local jugador = game.Players.LocalPlayer              -- el jugador que ejecuta este script
local personaje = jugador.Character                   -- personaje fisico del jugador
local canon = tool:WaitForChild("Canon")              -- espera a que el Canon este listo
local TweenService = game:GetService("TweenService")  -- para animar la bala

local gui = jugador.PlayerGui:WaitForChild("ScreenGui")
local texto = gui:WaitForChild("TextLabel")

local disparos = 0

tool.Activated:Connect(function()                     -- se dispara al hacer click con el Tool
    disparos = disparos + 1
    texto.Text = "Disparos: " .. disparos

    local camara = workspace.CurrentCamera
    local direccion = camara.CFrame.LookVector         -- hacia donde mira la camara

    local bala = Instance.new("Part")                  -- crea el proyectil
    bala.Size = Vector3.new(0.3, 0.3, 0.3)
    bala.Color = Color3.fromRGB(255, 255, 0)
    bala.Anchored = true
    bala.CanCollide = false
    bala.CFrame = CFrame.new(canon.Position)           -- sale desde el canon
    bala.Parent = workspace

    local destino = canon.Position + direccion * 200   -- 200 studs hacia adelante
    local tween = TweenService:Create(bala, TweenInfo.new(1), {Position = destino})
    tween:Play()

    game:GetService("Debris"):AddItem(bala, 3)         -- destruye la bala en 3 segundos
end)
```

### 4. Estructura en el Explorer

```
Workspace
  └── Tool
        ├── Handle
        │     └── WeldConstraint (Part0=Handle / Part1=Canon)
        ├── Canon
        └── LocalScript

StarterGui
  └── ScreenGui
        └── TextLabel
```

### 5. Extra: ¿por qué no le hace daño real a los NPCs?

Como todo el código está en un **LocalScript**, si intentás bajarle la vida a un NPC desde acá, ese cambio **solo se ve en tu pantalla**. Para los demás jugadores, el NPC sigue con toda su vida.

Esto pasa porque el `Tool.Activated` (el click con el arma) es algo que **solo tu cliente detecta con comodidad** (necesita tu cámara para saber hacia dónde apuntás). El daño, en cambio, tiene que ser **real para todos los jugadores**, y eso requiere que el cliente le avise al servidor lo que pasó.

> 💡 Esa comunicación cliente-servidor (RemoteEvents) es exactamente lo que vamos a ver en la **Clase 23**. Por ahora, la pistola se queda como galería de tiro visual, sin daño real a NPCs.
