# Clase 29: ¡Sube de Nivel! Sistema de XP 🌟

El jugador gana XP (puntos de experiencia) al completar retos del obby, sube de nivel cuando junta suficiente, y lo ve todo en una barra que se llena en pantalla.

## Objetivos

- Entender qué es una curva de progreso
- Guardar el nivel y la XP de cada jugador con atributos
- Mostrar una barra de XP animada en pantalla

## Contenido

### 1. ¿Qué es un sistema de XP?

Hacés cosas, ganás **XP**, y cuando juntás suficiente, **subís de nivel**. La **curva de progreso** es la regla que dice cuánta XP pide cada nivel. Nosotros usamos una simple: **cada nivel pide 100 × nivel**.

| Nivel | XP para subir |
|---|---|
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

> 💡 Al subir, lo que sobra se guarda: si tenías 90 de 100 y ganaste 50, pasás al nivel 2 con 40 de 200.

### 2. Paso 1: Tener el obby en su carpeta

Si todavía no lo tenés, armás el recorrido y guardás **todos** sus bloques en una carpeta:

1. Click derecho en **Workspace** → Insert Object → **Folder**, la renombrás `Obby`
2. Metés adentro todas las plataformas y obstáculos

```
Workspace
  └── Obby (Folder)
        ├── Plataforma
        ├── Plataforma
        └── ...
```

Esta carpeta es **solo para ordenar**: ningún script la usa.

### 3. Paso 2: Crear la carpeta de retos

1. Click derecho en **Workspace** → Insert Object → **Folder**
2. La renombrás `Retos`

```
Workspace
  ├── Obby (Folder)
  └── Retos (Folder)       ← acá van los bloques que dan XP
```

> ⚠️ Los retos van en su **propia** carpeta, no adentro de `Obby`. El script va a recorrer `Retos` y darle XP a todo lo que encuentre adentro.

### 4. Paso 3: Crear el primer reto

1. Click derecho en `Retos` → Insert Object → **Part**
2. La renombrás `Reto1`
3. En Properties:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Anchored** | `true` | Que no se caiga |
| **CanCollide** | `false` | Que se pueda atravesar, como un premio |
| **Material** | `Neon` | Que brille y se note |
| **Color** | Uno llamativo | Que se distinga de las plataformas |

4. Lo ubicás al final del primer tramo del obby

### 5. Paso 4: Decirle cuánta XP da

Cada reto guarda **su propia XP** en un **atributo** (Clase 27), así no hace falta tocar el código para cambiarla:

1. Con `Reto1` seleccionado, bajás hasta el final del panel **Properties**
2. En la sección **Atributos**, click en **+ Agregar atributo**
3. **Nombre**: `XP`
4. **Tipo**: `number`
5. Click en **Guardar**
6. En el atributo que apareció, escribís `50`

### 6. Paso 5: Ponerle un cartel con la XP

Para que el jugador sepa cuánto da cada reto antes de llegar, le ponemos un cartel flotante arriba, como el del NPC de la Clase 10:

1. Click derecho en `Reto1` → Insert Object → **BillboardGui**, lo renombrás `Cartel`
2. En Properties:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{0, 120}, {0, 40}` | Tamaño fijo en píxeles: el cartel se ve igual de grande de cerca y de lejos |
| **StudsOffset** | `0, 3, 0` | Lo sube 3 studs, para que flote arriba del reto |
| **AlwaysOnTop** | `true` | Se ve aunque haya una pared en el medio |

3. Click derecho en `Cartel` → Insert Object → **TextLabel**
4. En Properties:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{1, 0}, {1, 0}` | Ocupa todo el cartel |
| **BackgroundTransparency** | `1` | Sin fondo, solo el texto |
| **TextScaled** | `true` | El texto se ajusta al tamaño del cartel |
| **TextColor3** | El mismo color que el reto | Que se note que el cartel es de ese reto |
| **TextStrokeTransparency** | `0` | Le pone un borde negro a las letras, para que se lean sobre cualquier fondo |
| **Text** | `+50 XP` | Lo que dice el cartel |

```
Workspace
  └── Retos (Folder)
        └── Reto1 (XP = 50)
              └── Cartel (BillboardGui)
                    └── TextLabel ("+50 XP")
```

> 💡 Lo hacemos **antes** de duplicar: así, al hacer **Ctrl + D**, el cartel se copia junto con el reto y solo hay que cambiarle el texto.

### 7. Paso 6: Crear más retos

1. Seleccionás `Reto1` y **Ctrl + D** para duplicarlo
2. Lo renombrás `Reto2`, lo ubicás más adelante en el obby, le cambiás el atributo `XP` a `150` y el texto del cartel a `+150 XP`
3. Repetís para un `Reto3` al final, con `XP` en `300` y el cartel en `+300 XP`

```
Workspace
  ├── Obby (Folder)
  └── Retos (Folder)
        ├── Reto1 (XP = 50)
        │     └── Cartel → TextLabel ("+50 XP")
        ├── Reto2 (XP = 150)
        │     └── Cartel → TextLabel ("+150 XP")
        └── Reto3 (XP = 300)
              └── Cartel → TextLabel ("+300 XP")
```

> 💡 Cuanto más difícil es llegar al reto, más XP conviene que dé.

### 8. Paso 7: El script del servidor

1. Click derecho en **ServerScriptService** → Insert Object → **Script**
2. Lo renombrás `Experiencia`

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local carpetaRetos = workspace:WaitForChild("Retos")  -- la carpeta con los retos
local completados = {}                              -- completados[jugador] = los retos que ya hizo

local function darXP(jugador, cantidad)
    local xp = jugador:GetAttribute("XP") + cantidad  -- le suma la XP nueva
    local nivel = jugador:GetAttribute("Nivel")     -- su nivel actual

    while xp >= nivel * 100 do                      -- mientras le alcance para subir
        xp = xp - nivel * 100                       -- gasta la XP de este nivel
        nivel = nivel + 1                           -- sube uno

        local humanoid = jugador.Character and jugador.Character:FindFirstChild("Humanoid")
        if humanoid then
            humanoid.WalkSpeed = humanoid.WalkSpeed + 2  -- recompensa: un poco mas de velocidad
        end
    end

    jugador:SetAttribute("Nivel", nivel)            -- guarda el nivel
    jugador:SetAttribute("XP", xp)                  -- guarda la XP que sobro
end

local function alTocarReto(reto, parteQueToco)
    local jugador = Players:GetPlayerFromCharacter(parteQueToco.Parent)  -- busca que jugador lo toco
    if not jugador then return end                  -- si no es un jugador, nada

    completados[jugador] = completados[jugador] or {}  -- si es su primer reto, le crea su lista
    if completados[jugador][reto] then return end   -- si ya lo hizo, nada
    completados[jugador][reto] = true               -- lo marca como hecho

    darXP(jugador, reto:GetAttribute("XP") or 0)    -- le da la XP del reto
end

Players.PlayerAdded:Connect(function(jugador)       -- cuando entra un jugador
    jugador:SetAttribute("Nivel", 1)                -- arranca en nivel 1
    jugador:SetAttribute("XP", 0)                   -- con 0 de XP
end)

for _, reto in carpetaRetos:GetChildren() do        -- recorre todos los retos
    reto.Touched:Connect(function(parteQueToco)
        alTocarReto(reto, parteQueToco)
    end)
end
```

**Qué hace cada parte:**

- **Al entrar** (`PlayerAdded`): le pone al jugador dos atributos, `Nivel` en 1 y `XP` en 0
- **Al tocar un reto** (`alTocarReto`): revisa que sea un jugador y que no haya hecho ese reto antes, y le da la XP que dice el atributo del reto
- **Al dar XP** (`darXP`): suma la XP y, mientras alcance, sube de nivel. Usa `while` (Clase 20) por si un reto da tanta XP que sube **varios niveles de golpe**
- `completados` es una tabla de tablas (Clase 21): cada jugador puede hacer cada reto **una sola vez**. Se marca antes de dar la XP porque `Touched` se dispara por cada parte del cuerpo
- La recompensa es **+2 de velocidad** por cada nivel que sube

> ⚠️ Ojo con escribir bien `GetAttribute` y `SetAttribute`, con **dos t**. Con una sola, el script tira error al tocar el reto y la XP nunca se suma.

### 9. Paso 8: Crear la barra

1. Click derecho en **StarterGui** → Insert Object → **ScreenGui**, la renombrás `XPGui`
2. Click derecho en `XPGui` → Insert Object → **Frame**, lo renombrás `Fondo`:
   - **Size**: `{0.4, 0}, {0.05, 0}`
   - **Position**: `{0.3, 0}, {0.92, 0}`
   - **BackgroundColor3**: gris oscuro
3. Click derecho en `Fondo` → Insert Object → **Frame**, lo renombrás `Relleno`:
   - **Size**: `{0, 0}, {1, 0}` (arranca vacío)
   - **BackgroundColor3**: verde
4. Click derecho en `Fondo` → Insert Object → **TextLabel**, lo renombrás `TextoNivel`:
   - **Size**: `{1, 0}, {1, 0}`
   - **BackgroundTransparency**: `1`
   - **TextScaled**: `true`
   - **ZIndex**: `2` (para que el relleno no lo tape)
5. Click derecho en `Fondo` → Insert Object → **LocalScript**

```
StarterGui
  └── XPGui (ScreenGui)
        └── Fondo (Frame)
              ├── Relleno (Frame)
              ├── TextoNivel (TextLabel)
              └── LocalScript
```

### 10. Paso 9: El código de la barra

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores
local TweenService = game:GetService("TweenService")  -- para animar la barra

local jugador = Players.LocalPlayer                 -- el jugador que ve esta pantalla
local relleno = script.Parent:WaitForChild("Relleno")  -- la parte que se llena
local texto = script.Parent:WaitForChild("TextoNivel") -- el texto de la barra

local function actualizarBarra()
    local nivel = jugador:GetAttribute("Nivel") or 1  -- lee el nivel
    local xp = jugador:GetAttribute("XP") or 0      -- lee la XP
    local necesaria = nivel * 100                   -- la misma curva que el servidor

    texto.Text = "Nivel " .. nivel .. " — " .. xp .. " / " .. necesaria .. " XP"
    TweenService:Create(relleno, TweenInfo.new(0.5), {Size = UDim2.new(xp / necesaria, 0, 1, 0)}):Play()  -- llena la barra animada
end

actualizarBarra()                                   -- dibuja la barra al empezar
jugador:GetAttributeChangedSignal("XP"):Connect(actualizarBarra)     -- y cada vez que cambia la XP
jugador:GetAttributeChangedSignal("Nivel"):Connect(actualizarBarra)  -- o el nivel
```

- La barra **no calcula nada**: solo lee los atributos que guardó el servidor
- `xp / necesaria` da un número de 0 a 1: con 50 de 100 da `0.5`, o sea, media barra
- `UDim2.new(porcentaje, 0, 1, 0)`: el ancho según la XP y todo el alto (Clase 16)
- `nivel * 100` tiene que ser **la misma curva** que en el servidor

### 12. Probar

1. **Play**: la barra arranca en `Nivel 1 — 0 / 100 XP`
2. Llegás a `Reto1`: la barra se llena hasta la mitad, `50 / 100`
3. Lo volvés a tocar: no pasa nada
4. Llegás a `Reto2`: sumás 150, subís al **nivel 2**, quedás en `100 / 200` y corrés un poco más rápido
5. Llegás a `Reto3`: sumás 300 y subís al **nivel 3**

### 13. Problemas comunes

| Problema | Solución |
|---|---|
| Un reto no da XP | Revisar que tenga el atributo `XP` y que esté dentro de `Retos`, no de `Obby` |
| Error `GetAtribute is not a valid member` | Falta una t: es `GetAttribute` |
| No se ve el texto de la barra | Poner **ZIndex** del TextoNivel en `2` |
| La barra se pasa del fondo | Revisar que la curva sea `nivel * 100` en los dos scripts |
| Al morir pierdo la velocidad | Es normal en esta versión: el personaje nuevo arranca con 16 |

### 14. Extras

**Una curva más difícil:** cambiá `nivel * 100` por `100 * 1.5 ^ (nivel - 1)` en los dos scripts. Los niveles altos cuestan mucho más, como en muchos juegos de Roblox.

**El nivel se pierde al salir:** se guarda en la Clase 31 (DataStore).
