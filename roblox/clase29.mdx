# Clase 29: ¡Sube de Nivel! Sistema de XP 🌟

Completás retos del obby, ganás XP y subís de nivel, con una barra que se llena en pantalla.

## Objetivos

- Guardar el nivel y la XP de cada jugador con atributos
- Subir de nivel con una curva de progreso
- Mostrar una barra de XP animada

## Contenido

La **curva de progreso** dice cuánta XP pide cada nivel. La nuestra: **nivel × 100** (el 1 pide 100, el 2 pide 200, el 3 pide 300). Al subir, lo que sobra se guarda.

### 🧱 Parte 1: Los retos

### Paso 1: Las dos carpetas

1. Click derecho en **Workspace** → Insert Object (**Insertar objeto**) → **Folder**, la renombrás `Obby` y metés adentro todas las plataformas del recorrido
2. Otra **Folder** en Workspace, llamada `Retos`: acá van los bloques que dan XP

> 📝 **Para qué dos carpetas:** `Obby` es solo para ordenar (ningún script la usa). `Retos` la recorre el script con un `for` para conectar cada reto: todo lo que esté adentro da XP.

> ⚠️ Los retos van en su **propia** carpeta, no adentro de `Obby`: el script recorre `Retos`.

### Paso 2: El primer reto

Click derecho en `Retos` → Insert Object (**Insertar objeto**) → **Part**, la renombrás `Reto1`:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Anchored** | `true` | Queda fijo, no se cae |
| **CanCollide** | `false` | Se atraviesa, como un premio que agarrás al pasar |
| **Material** | `Neon` | Brilla y se nota de lejos |
| **Color** | Uno llamativo | Que se distinga de las plataformas |

Lo ponés al final del primer tramo del obby.

### Paso 3: La XP en un atributo

Cada reto guarda su XP en un **atributo** (Clase 27), así se cambia sin tocar el código:

> 📝 **Qué es un atributo:** un dato con nombre que le pegás a un objeto, como una etiqueta (`XP = 50`). El script lo lee con `GetAttribute("XP")`.

1. Con `Reto1` seleccionado, bajás hasta el final de **Propiedades**
2. En **Atributos**, click en **+**
3. **Nombre** `XP`, **Tipo** `number` → **Guardar**
4. Le escribís `50`

![El atributo XP del reto](roblox/img/clase29/01-atributo-xp.png)
*Al final de Propiedades, en **Atributos**: XP = 50.*

> 💡 No lo confundas con **Etiquetas**, la sección de arriba: son nombres sin valor para marcar objetos. Para guardar un número, como la XP, va un atributo.

### Paso 4: El cartel

Un cartel flotante con la XP, como el del NPC de la Clase 10:

1. Click derecho en `Reto1` → Insert Object (**Insertar objeto**) → **BillboardGui**, lo renombrás `Cartel`

> 📝 **Qué es un BillboardGui:** un cartel pegado a una Part que siempre mira a la cámara. Adentro lleva textos, como un ScreenGui pero en el mundo 3D.

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** ✏️ | `{0, 120}, {0, 40}` | 120 × 40 píxeles fijos: se ve del mismo tamaño de cerca y de lejos |
| **StudsOffset** ✏️ | `0, 3, 0` | Lo sube 3 studs, para que flote arriba del reto |
| **AlwaysOnTop** ✏️ | `true` | Se ve aunque haya algo en el medio |
| **MaxDistance** | infinito | Desde qué distancia deja de verse |
| **Adornee** | vacío | A qué Part se pega. Vacío = a la Part que lo contiene (el reto) |

*✏️ = las que cambiamos. Las demás (Brightness, LightInfluence…) quedan como vienen.*

2. Adentro de `Cartel`, un **TextLabel**:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{1, 0}, {1, 0}` | Ocupa todo el cartel |
| **BackgroundTransparency** | `1` | Sin fondo, solo las letras |
| **TextScaled** | `true` | El texto se ajusta al tamaño del cartel |
| **TextColor3** | El color del reto | Que se note de qué reto es |
| **TextStrokeTransparency** | `0` | Borde negro en las letras, para leerlas sobre cualquier fondo |
| **Text** | `+50 XP` | Lo que dice el cartel |

> 💡 Hacé el cartel **antes** de duplicar: con **Ctrl + D** se copia junto con el reto.

### Paso 5: Más retos

**Ctrl + D** sobre `Reto1` y armás:
- `Reto2`, más adelante: atributo `XP` en `150` y cartel `+150 XP`
- `Reto3`, al final: atributo `XP` en `300` y cartel `+300 XP`

![El obby con los tres retos](roblox/img/clase29/02-escena.png)

### ⚙️ Parte 2: El servidor

### Paso 1: El script Experiencia

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `Experiencia`:

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local carpetaRetos = workspace:WaitForChild("Retos")  -- la carpeta con los retos
local completados = {}                              -- completados[jugador] = los retos que ya hizo

local function darXP(jugador, cantidad)
    local xp = jugador:GetAttribute("XP") + cantidad  -- le suma la XP nueva
    local nivel = jugador:GetAttribute("Nivel")     -- su nivel actual

    while xp >= nivel * 100 do                      -- mientras le alcance para subir
        xp = xp - nivel * 100                       -- gasta la XP de este nivel
        nivel = nivel + 1                           -- sube uno

        local humanoid = jugador.Character and jugador.Character:FindFirstChild("Humanoid")
        if humanoid then
            humanoid.WalkSpeed = humanoid.WalkSpeed + 2  -- recompensa: un poco mas de velocidad
        end
    end

    jugador:SetAttribute("Nivel", nivel)            -- guarda el nivel
    jugador:SetAttribute("XP", xp)                  -- guarda la XP que sobro
end

local function alTocarReto(reto, parteQueToco)
    local jugador = Players:GetPlayerFromCharacter(parteQueToco.Parent)  -- busca que jugador lo toco
    if not jugador then return end                  -- si no es un jugador, nada

    completados[jugador] = completados[jugador] or {}  -- si es su primer reto, le crea su lista
    if completados[jugador][reto] then return end   -- si ya lo hizo, nada
    completados[jugador][reto] = true               -- lo marca como hecho

    darXP(jugador, reto:GetAttribute("XP") or 0)    -- le da la XP del reto
end

Players.PlayerAdded:Connect(function(jugador)       -- cuando entra un jugador
    jugador:SetAttribute("Nivel", 1)                -- arranca en nivel 1
    jugador:SetAttribute("XP", 0)                   -- con 0 de XP
end)

for _, reto in carpetaRetos:GetChildren() do        -- recorre todos los retos
    reto.Touched:Connect(function(parteQueToco)
        alTocarReto(reto, parteQueToco)
    end)
end
```

- **Al entrar**: cada jugador arranca con los atributos `Nivel` = 1 y `XP` = 0
- **Al tocar un reto**: le da la XP del atributo, **una sola vez** por reto (la tabla `completados`, Clase 21)
- **`darXP`**: el `while` (Clase 20) sube varios niveles de golpe si alcanza, y cada nivel da **+2 de velocidad** (**WalkSpeed**, que arranca en 16)
- `SetAttribute` guarda `Nivel` y `XP` en el jugador; como lo hace el servidor, la barra del cliente se entera sola

> ⚠️ `GetAttribute` y `SetAttribute` van con **dos t**. Con una sola, la XP nunca se suma.

### 📊 Parte 3: La barra

### Paso 1: Armar la barra

La barra son dos rectángulos: el `Fondo` gris y, encima, el `Relleno` verde que se estira según la XP.

1. Click derecho en **StarterGui** → **ScreenGui**, la renombrás `XPGui`
2. Adentro, un **Frame** `Fondo`:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{0.4, 0}, {0.05, 0}` | 40% del ancho y 5% del alto de la pantalla |
| **Position** | `{0.3, 0}, {0.92, 0}` | Centrada y abajo de todo |
| **BackgroundColor3** | Gris oscuro | La parte vacía de la barra |

3. Adentro de `Fondo`, un **Frame** `Relleno`:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{0, 0}, {1, 0}` | Ancho 0: arranca vacía. El script le cambia el ancho |
| **BackgroundColor3** | Verde | La parte llena de la barra |

4. Adentro de `Fondo`, un **TextLabel** `TextoNivel`:

| Propiedad | Valor | Para qué sirve |
|---|---|---|
| **Size** | `{1, 0}, {1, 0}` | Ocupa toda la barra |
| **BackgroundTransparency** | `1` | Sin fondo, para ver la barra detrás |
| **TextScaled** | `true` | El texto se ajusta al tamaño |
| **TextColor3** | Blanco | Que se lea sobre el gris y el verde |
| **ZIndex** | `2` | Lo dibuja encima del relleno, que tiene 1 |

### Paso 2: El LocalScript

Click derecho en `Fondo` → Insert Object (**Insertar objeto**) → **LocalScript**:

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores
local TweenService = game:GetService("TweenService")  -- para animar la barra

local jugador = Players.LocalPlayer                 -- el jugador que ve esta pantalla
local relleno = script.Parent:WaitForChild("Relleno")  -- la parte que se llena
local texto = script.Parent:WaitForChild("TextoNivel") -- el texto de la barra

local function actualizarBarra()
    local nivel = jugador:GetAttribute("Nivel") or 1  -- lee el nivel
    local xp = jugador:GetAttribute("XP") or 0      -- lee la XP
    local necesaria = nivel * 100                   -- la misma curva que el servidor

    texto.Text = "Nivel " .. nivel .. " — " .. xp .. " / " .. necesaria .. " XP"
    TweenService:Create(relleno, TweenInfo.new(0.5), {Size = UDim2.new(xp / necesaria, 0, 1, 0)}):Play()  -- llena la barra animada
end

actualizarBarra()                                   -- dibuja la barra al empezar
jugador:GetAttributeChangedSignal("XP"):Connect(actualizarBarra)     -- y cada vez que cambia la XP
jugador:GetAttributeChangedSignal("Nivel"):Connect(actualizarBarra)  -- o el nivel
```

- La barra **no calcula nada**: lee los atributos que guardó el servidor
- `xp / necesaria` da de 0 a 1: con 50 de 100, media barra
- `TweenService` anima el cambio de tamaño en medio segundo, en vez de saltar de golpe
- `GetAttributeChangedSignal` vuelve a dibujar la barra cada vez que cambian la XP o el nivel
- `nivel * 100` tiene que ser **la misma curva** que en el servidor

### Problemas comunes

| Problema | Solución |
|---|---|
| Un reto no da XP | Tiene que tener el atributo `XP` y estar dentro de `Retos`, no de `Obby` |
| Error `GetAtribute is not a valid member` | Falta una t: es `GetAttribute` |
| No se lee el texto de la barra | **TextColor3** blanco y **ZIndex** `2` en `TextoNivel` |
| La barra se pasa del fondo | La curva tiene que ser `nivel * 100` en los dos scripts |
| Al morir pierdo la velocidad | Es normal: el personaje nuevo arranca con 16 |

### Extras

**Una curva más difícil:** cambiá `nivel * 100` por `100 * 1.5 ^ (nivel - 1)` en los dos scripts.

**El nivel se pierde al salir:** se guarda con DataStore en la Clase 31.
