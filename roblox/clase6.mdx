# Clase 6: Nuestro primer print 💻

Damos nuestros primeros pasos en programación con Lua: hacemos un print, usamos variables y empezamos a programar un bloque.

## Objetivos

- Hacer tu primer print en la consola
- Usar variables
- Aplicar una propiedad, un método y un evento sobre un Part

## Contenido

### 1. Insertar un Script

1. Click derecho sobre una Part → Insert Object → **Script**
2. Se abre el editor de código

### 2. Hacer tu primer print

```lua
print("Hola mundo")
```

Al darle Play, `"Hola mundo"` aparece en la consola (Output).

### 3. Usar variables

```lua
local nombre = "Roblox"
local numero = 10
print(nombre)   -- imprime: Roblox
print(numero)   -- imprime: 10
```

> 💡 `local` significa que la variable solo existe dentro del script donde se declara.

### 4. Referenciar el bloque y usar una propiedad

```lua
local bloque = script.Parent                -- el Part que contiene el script
bloque.Color = Color3.fromRGB(255, 0, 0)    -- propiedad: cambia el color
```

### 5. Usar un método

```lua
local clon = bloque:Clone()   -- metodo: crea una copia del bloque
clon.Parent = workspace       -- la agrega al mundo
```

### 6. Usar un evento

```lua
bloque.Touched:Connect(function()
    print("me tocaron!")
end)
```

**Ejemplo:** cada vez que algo toca el bloque, imprime `"me tocaron!"` en la consola.

## Ejercicio

> Consigna: Programá un método, una propiedad y un evento del Part.

**Pistas:**
1. Empezá siempre con `local bloque = script.Parent` para referenciar tu Part
2. Probá combinar el evento `Touched` con un cambio de propiedad
3. Usá la consola (Output) para verificar que tu código corre bien
