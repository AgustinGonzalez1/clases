# Clase 15: Cutscenes en Roblox 🎬

Creamos una cinemática básica controlando la cámara del jugador con código, usando un punto de referencia en el mapa.

## Objetivos

- Tomar el control de la cámara desde código
- Animar la cámara con TweenService
- Bloquear y devolver el control del jugador durante la cinemática

## Contenido

### 1. Preparar el punto de cámara

1. Workspace → Insert Object → **Folder** → `Cinematica`
2. Dentro, una Part `Punto1`, con **Transparency=1** y **CanCollide=false**
3. La posicionás y orientás donde querés que mire la cámara

### 2. El LocalScript

Va en **StarterGui**.

```lua
local camera = workspace.CurrentCamera
local TweenService = game:GetService("TweenService")
local jugador = game.Players.LocalPlayer
local personaje = jugador.Character or jugador.CharacterAdded:Wait()
local humanoid = personaje:WaitForChild("Humanoid")

wait(1)

humanoid.WalkSpeed = 0
humanoid.JumpHeight = 0

camera.CameraType = Enum.CameraType.Scriptable

local puntoDestino = workspace.Cinematica.Punto1

local tween = TweenService:Create(camera, TweenInfo.new(3), {CFrame = puntoDestino.CFrame})
tween:Play()
tween.Completed:Wait()

camera.CameraType = Enum.CameraType.Custom
humanoid.WalkSpeed = 16
humanoid.JumpHeight = 7.2
```

### 3. Extra: texto en pantalla

1. StarterGui → Insert Object → **ScreenGui** → **TextLabel**
2. Agregás al script:

```lua
local gui = jugador.PlayerGui:WaitForChild("ScreenGui")
local texto = gui:WaitForChild("TextLabel")

texto.Text = "Bienvenido al juego..."
-- (el tween va acá)
texto.Text = ""
```

## Ejercicio

> Consigna: Creá tu primera cinemática moviendo la cámara desde el spawn hasta un punto del mapa.

**Pistas:**
1. `Enum.CameraType.Scriptable` es lo que te da control manual sobre la cámara
2. No olvides devolver `Enum.CameraType.Custom` al terminar, sino el jugador queda sin control de cámara
3. `WalkSpeed = 0` bloquea el movimiento del jugador durante la cinemática
