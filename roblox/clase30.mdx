# Clase 30: Tiendas y Monedas Virtuales 🛍️

Juntamos monedas en el mapa y las gastamos en una tienda que se abre con la **E**.

## Objetivos

- Usar una columna del leaderboard como moneda
- Abrir una tienda con un `ProximityPrompt`
- Cobrar desde el servidor con un `RemoteEvent`

## Contenido

### 🪙 Parte 1: Las monedas

### Paso 1: Crear la carpeta

### Paso 2: Crear la moneda

### Paso 4: El script Economia

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `Economia`:

```lua
local Players = game:GetService("Players")          -- servicio que maneja a los jugadores

local VALOR_MONEDA = 10                             -- cuantas monedas da cada moneda del mapa
local TIEMPO_REAPARICION = 5                        -- segundos que tarda en volver a aparecer

local carpetaMonedas = workspace:WaitForChild("Monedas")  -- la carpeta con todas las monedas

local function crearTabla(jugador)
    local leaderstats = Instance.new("Folder")      -- crea la carpeta de la tabla
    leaderstats.Name = "leaderstats"                -- con este nombre exacto, Roblox la muestra

    local monedas = Instance.new("IntValue")        -- crea la columna de monedas
    monedas.Name = "Monedas"                        -- el nombre que se ve en la tabla
    monedas.Value = 0                               -- arranca sin monedas
    monedas.Parent = leaderstats                    -- la mete en la carpeta

    leaderstats.Parent = jugador                    -- le pone la carpeta al jugador
end

local function alTocarMoneda(moneda, parteQueToco)
    local jugador = Players:GetPlayerFromCharacter(parteQueToco.Parent)  -- busca que jugador la toco
    if not jugador or not moneda.CanTouch then return end  -- si no es un jugador o ya la agarraron, no hace nada

    local monedas = jugador.leaderstats.Monedas     -- la columna de monedas de ese jugador
    monedas.Value = monedas.Value + VALOR_MONEDA    -- le suma las monedas

    moneda.Transparency = 1                         -- la hace invisible
    moneda.CanTouch = false                         -- y que no se pueda volver a tocar
    task.wait(TIEMPO_REAPARICION)                   -- espera unos segundos
    moneda.Transparency = 0                         -- vuelve a aparecer
    moneda.CanTouch = true                          -- y se puede agarrar de nuevo
end

Players.PlayerAdded:Connect(crearTabla)             -- cada vez que entra un jugador, le crea su tabla

for _, moneda in carpetaMonedas:GetChildren() do    -- recorre todas las monedas de la carpeta
    moneda.Touched:Connect(function(parteQueToco)   -- cuando alguien toca esta moneda
        alTocarMoneda(moneda, parteQueToco)
    end)
end
```

Es el script de la Clase 28, pero la columna se llama `Monedas`.

**Probalo:** Play, apretá **Tab** para ver la tabla y tocá una moneda: sumás 10.

### Paso 4: El LocalScript

Click derecho en `Ventana` → Insert Object (**Insertar objeto**) → **LocalScript**:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")  -- donde esta el RemoteEvent

local comprar = ReplicatedStorage:WaitForChild("Comprar")       -- el RemoteEvent de las compras
local prompt = workspace:WaitForChild("Tienda"):WaitForChild("ProximityPrompt")  -- el cartel de la tienda
local ventana = script.Parent                       -- la ventana de la tienda

local function abrirTienda()
    ventana.Mensaje.Text = ""                       -- borra el mensaje anterior
    ventana.Visible = true                          -- muestra la ventana
end

local function cerrarTienda()
    ventana.Visible = false                         -- oculta la ventana
end

local function mostrarMensaje(texto)
    ventana.Mensaje.Text = texto                    -- muestra lo que respondio el servidor
end

prompt.Triggered:Connect(abrirTienda)               -- al apretar E en la tienda
ventana.Cerrar.Activated:Connect(cerrarTienda)      -- al tocar Cerrar

ventana.ComprarVelocidad.Activated:Connect(function()
    comprar:FireServer("Velocidad")                 -- pide la Velocidad: manda solo el nombre, nunca el precio
end)

ventana.ComprarSalto.Activated:Connect(function()
    comprar:FireServer("Salto")                     -- pide el Salto
end)

comprar.OnClientEvent:Connect(mostrarMensaje)       -- cuando el servidor responde, muestra el mensaje
```

- La **E** abre la ventana y **Cerrar** la cierra
- Cada botón manda **solo el nombre** del poder, nunca el precio
- Lo que responde el servidor se muestra en `Mensaje`

### ⚡ Parte 4: Cobrar en el servidor

### Paso 1: El script Tienda

Click derecho en **ServerScriptService** → Insert Object (**Insertar objeto**) → **Script**, lo renombrás `Tienda`:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")  -- donde esta el RemoteEvent

local PRECIOS = {                                   -- la lista de precios: la decide el servidor
    Velocidad = 30,
    Salto = 50,
}

local comprar = ReplicatedStorage:WaitForChild("Comprar")  -- el RemoteEvent de las compras

local function alPedirCompra(jugador, nombreItem)
    local precio = PRECIOS[nombreItem]              -- busca el precio en la lista del servidor
    if not precio then return end                   -- si no esta en la lista, no hace nada

    local personaje = jugador.Character             -- el personaje del jugador
    local humanoid = personaje and personaje:FindFirstChild("Humanoid")  -- su Humanoid
    if not humanoid then return end                 -- si todavia no aparecio, no hace nada

    if personaje:GetAttribute(nombreItem) then      -- si ya lo compro en esta vida
        comprar:FireClient(jugador, "Ya compraste " .. nombreItem)  -- le avisa y no le cobra
        return
    end

    local monedas = jugador.leaderstats.Monedas     -- la columna de monedas de ese jugador
    if monedas.Value < precio then                  -- si no le alcanza
        comprar:FireClient(jugador, "Te faltan " .. (precio - monedas.Value) .. " monedas")  -- le avisa cuanto le falta
        return
    end

    monedas.Value = monedas.Value - precio          -- le cobra
    personaje:SetAttribute(nombreItem, true)        -- anota que ya lo compro

    if nombreItem == "Velocidad" then
        humanoid.WalkSpeed = 32                     -- el doble de lo normal (16)
    elseif nombreItem == "Salto" then
        humanoid.JumpHeight = 20                    -- casi el triple de lo normal (7.2)
    end

    comprar:FireClient(jugador, "¡Compraste " .. nombreItem .. "!")  -- le confirma la compra
end

comprar.OnServerEvent:Connect(alPedirCompra)        -- cada vez que un boton pide una compra
```

- El precio sale de la lista `PRECIOS` del servidor
- Si no te alcanza, te dice cuánto te falta; si ya lo compraste, no te cobra de nuevo
- El poder dura hasta que morís: el personaje nuevo arranca normal

> ⚠️ El precio **nunca** lo manda el botón. Si lo mandara, un tramposo podría comprar todo por 0 monedas.

![Los tres mensajes del servidor](roblox/img/clase30/05-mensajes.png)
*Las tres respuestas: compra lista, no te alcanza y ya lo tenías.*

### Problemas comunes

| Problema | Solución |
|---|---|
| La tienda aparece abierta al empezar | **Visible** de `Ventana` en `false` |
| Aprieto E y no se abre | El LocalScript tiene que estar dentro de `Ventana` y la Part llamarse `Tienda` |
| Toco un botón y no pasa nada | El nombre que manda el botón tiene que estar igual en `PRECIOS`: `Velocidad` y `Salto` |
| Al morir pierdo el poder | Es a propósito: se vuelve a comprar |

### Extras

**Un tercer poder:** sumá `Luna = 40` a `PRECIOS`, un botón que mande `"Luna"`, y en el `if` del servidor:

```lua
    elseif nombreItem == "Luna" then
        humanoid.JumpHeight = 50                    -- salto altisimo
        humanoid.WalkSpeed = 10                     -- pero mas lento
```

**Las monedas se pierden al salir:** se guardan con DataStore en la Clase 31.
