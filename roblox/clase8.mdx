# Bloque teletransportador 🔀

En esta clase creamos un bloque teletransportador usando un emisor y un receptor, y además un bloque que se clona, se anima y desaparece.

---

## ¿Qué es TweenService?

**TweenService** es un servicio de Roblox que permite animar propiedades de objetos suavemente entre dos estados. Se accede con `game:GetService("TweenService")`.

---

## Métodos nuevos

| Método | Qué hace |
|---|---|
| `Clone()` | Crea una copia exacta del objeto |
| `Destroy()` | Elimina el objeto del juego |
| `:MoveTo(Vector3)` | Mueve el personaje a una posición en el mundo |

---

## ¿Qué es un Vector3?

Un **Vector3** es un conjunto de tres números que representa una posición o dirección en el espacio 3D: `Vector3.new(x, y, z)`.

Por ejemplo `Vector3.new(0, 10, 50)` representa la posición x=0, y=10, z=50 en el mundo.

---

## Bloque teletransportador

Hay un **bloque emisor** que al tocarlo mueve al jugador hasta la posición del **bloque receptor**.

```lua
local emisor = script.Parent              -- el bloque que se toca
local receptor = workspace.Receptor       -- el bloque destino

emisor.Touched:Connect(function(mano)
    local personaje = mano.Parent
    personaje:MoveTo(receptor.Position)   -- mueve al jugador a la posicion del receptor
end)
```

> ⚠️ El bloque receptor tiene que llamarse exactamente `Receptor` en el Explorer. Si lo movés en el mapa, la teletransportación cambia sola sin tocar el código.

### Estructura en el Explorer

```
Workspace
  ├── Emisor (Part con Script adentro)
  └── Receptor (Part sin script, solo marca el destino)
```

## Bloque que se clona, se anima y desaparece

Al tocar el bloque se crea una copia, se mueve suavemente y luego desaparece.

```lua
local bloque = script.Parent
local TweenService = game:GetService("TweenService")  -- servicio para animar
local activado = false                                 -- evita que se active varias veces

bloque.Touched:Connect(function()
    if activado then return end   -- si ya se activo, no hace nada
    activado = true

    -- Clona el bloque
    local clon = bloque:Clone()                        -- crea una copia
    clon.Color = Color3.fromRGB(255, 0, 0)             -- cambia el color para distinguirlo
    clon.Parent = workspace                            -- lo agrega al mundo

    -- Lo anima suavemente hacia una nueva posicion
    local info = TweenInfo.new(2)                      -- duracion: 2 segundos
    local meta = {Position = clon.Position + Vector3.new(10, 5, 0)} -- posicion destino
    local tween = TweenService:Create(clon, info, meta)
    tween:Play()                                       -- arranca la animacion

    -- Lo destruye al terminar
    wait(2)
    clon:Destroy()                                     -- elimina el clon

    activado = false  -- permite que se active de nuevo
end)
```

---

## ¿Cómo funciona TweenService?

`TweenService:Create()` recibe tres parámetros:

| Parámetro | Qué es |
|---|---|
| El objeto | Qué se anima |
| TweenInfo | Cómo se anima (duración, curva) |
| La tabla `{}` | A dónde llega (propiedad y valor final) |
