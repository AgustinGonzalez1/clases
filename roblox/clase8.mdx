# Clase 8: Bloque teletransportador 🔀

---

## Paso 1: Crear el bloque emisor y el receptor

1. Insertás dos Parts en el Workspace
2. Una la nombrás `Emisor` (con el Script adentro)
3. La otra la nombrás `Receptor` (marca el destino, sin script)

```
Workspace
  ├── Emisor (Part con Script)
  └── Receptor (Part)
```

---

## Paso 2: Programar el teletransporte

```lua
local emisor = script.Parent
local receptor = workspace.Receptor

emisor.Touched:Connect(function(mano)
    local personaje = mano.Parent
    personaje:MoveTo(receptor.Position)   -- mueve al jugador a la posicion del receptor
end)
```

> ⚠️ El bloque receptor tiene que llamarse exactamente `Receptor`. Si lo movés en el mapa, la teletransportación cambia sola sin tocar el código.

---

## Paso 3: Crear un bloque que se clona, se anima y desaparece

```lua
local bloque = script.Parent
local TweenService = game:GetService("TweenService")
local activado = false

bloque.Touched:Connect(function()
    if activado then return end
    activado = true

    local clon = bloque:Clone()               -- crea una copia
    clon.Color = Color3.fromRGB(255, 0, 0)
    clon.Parent = workspace

    local info = TweenInfo.new(2)              -- duracion: 2 segundos
    local meta = {Position = clon.Position + Vector3.new(10, 5, 0)}
    local tween = TweenService:Create(clon, info, meta)
    tween:Play()

    wait(2)
    clon:Destroy()

    activado = false
end)
```

---

## Misión

> Tocar un bloque que se clone, se anime y luego desaparezca.
