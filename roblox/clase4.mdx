# Clase 4: ¡A Mover el Esqueleto! 🕺

Creamos animaciones con el Animation Editor usando el personaje estándar de Roblox, y exploramos la edición de expresiones faciales.

## Objetivos

- Conocer el Animation Editor y sus conceptos clave
- Crear una animación con Loop y otra sin Loop
- Publicar una animación y obtener su ID
- Explorar el Face Animation Editor para crear expresiones faciales

## Contenido

### 1. Abrir el Animation Editor

Se abre desde la pestaña **Avatar → Animation Editor**. Viene integrado en Studio, no requiere plugins. Seleccionás el personaje en el Workspace y aparece la línea de tiempo.

> ⚠️ Roblox lanzó el **Avatar Joint Upgrade**, que reemplaza las uniones Motor6D del personaje estándar por un sistema nuevo (AnimationConstraint + BallSocketConstraint) para permitir física más realista. Es el comportamiento **default en experiencias nuevas** desde 2026. El flujo de trabajo del Animation Editor (crear keyframes, mover partes, publicar) sigue siendo el mismo para vos, pero si algo se ve raro al animar el personaje estándar (por ejemplo el modo IK), puede estar relacionado con esta actualización.

### 2. Conceptos clave

| Concepto | Qué es |
|---|---|
| **Keyframe** | Un momento en el tiempo donde definís una pose |
| **Timeline** | La línea de tiempo donde van los keyframes |
| **Loop** | Si la animación se repite al terminar |

**Ejemplo:** un keyframe en el segundo 0 con el brazo abajo, y otro en el segundo 1 con el brazo arriba, crea un movimiento de saludo entre esos dos puntos.

### 3. Crear la animación de caminar (con Loop)

1. Keyframe en 0 → pose neutral
2. Keyframe en 0.5s → pierna derecha adelante, brazo izquierdo adelante
3. Keyframe en 1s → vuelve a neutral
4. Activás **Loop**

### 4. Crear la animación de saludar (sin Loop)

1. Keyframe en 0 → pose neutral
2. Keyframe en 0.3s → brazo derecho levantado
3. Keyframe en 0.6s → brazo un poco abajo
4. Keyframe en 0.9s → brazo arriba de nuevo
5. Keyframe en 1.2s → pose neutral

### 5. Previsualizar y publicar

| Acción | Cómo | Para qué |
|---|---|---|
| **Previsualizar** | Botón Play dentro del editor | Ver cómo queda antes de publicar |
| **Publicar** | Save to Roblox | Genera un ID para usar en la Clase 14 |

> ⚠️ Anotá el ID de cada animación publicada. Lo vas a necesitar más adelante.

### 6. Extra: edición facial con el Face Animation Editor

Además de animar el cuerpo, Roblox permite animar la **cara** del personaje con el **Face Animation Editor**, integrado en el mismo Animation Editor.

1. Con el personaje seleccionado y el Animation Editor abierto, buscás el botón **Face** en la lista de tracks
2. Se abren **sliders** (controles deslizantes) para cada parte de la cara: ojos, cejas, boca, etc.
3. Movés los sliders hasta lograr la expresión que quieras (por ejemplo sonrisa, sorpresa, enojo)
4. Cada ajuste se guarda automáticamente como un keyframe en la línea de tiempo, igual que con el cuerpo

> ⚠️ No todos los personajes soportan esto. Necesitás una cabeza compatible (**Animatable Head**), como las que vienen en ciertos avatares del Marketplace. Si tu personaje no tiene esa opción, el botón **Face** no va a aparecer.

**Ejemplo:** combinar una animación de saludo del cuerpo con una expresión de sonrisa en la cara al mismo tiempo, en la misma línea de tiempo, da como resultado un saludo mucho más expresivo.

## Ejercicio

> Consigna: Exportá (publicá) y previsualizá 2 animaciones propias: una con Loop (caminar) y otra sin Loop (saludo). Si tu personaje soporta cabeza animable, agregale una expresión facial a alguna de las dos.

**Pistas:**
1. Usá al menos 3 keyframes por animación para que se note el movimiento
2. No olvides activar **Loop** solo en la animación de caminar
3. Anotá el ID de cada animación publicada, lo vas a necesitar en la Clase 14
4. Si el botón **Face** no aparece, probá con un personaje que tenga cabeza animable del Marketplace
