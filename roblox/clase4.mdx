# ¡A Mover el Esqueleto! 🕺

En esta clase aprendemos a crear animaciones con el Animation Editor usando el personaje estándar de Roblox.

---

## ¿Qué es el Animation Editor?

Es una herramienta integrada en Roblox Studio que permite mover los huesos del personaje cuadro por cuadro para crear animaciones. No necesitás saber programar para usarlo.

Se abre desde la pestaña **Avatar → Animation Editor**. Luego seleccionás el personaje en el Workspace y aparece la línea de tiempo.

---

## Conceptos clave

### Keyframe

Un **keyframe** es un momento específico en la línea de tiempo donde definís una pose. Roblox calcula automáticamente los movimientos intermedios entre keyframes.

> 💡 Pensalo como una foto: cada keyframe es una foto de cómo está el personaje en ese momento.

### Timeline

La **línea de tiempo** muestra todos los keyframes de la animación. Podés hacer zoom para ver más detalle o arrastrar los keyframes para cambiar su tiempo.

### Loop

Si activás **Loop**, la animación se repite infinitamente al terminar. Ideal para animaciones de caminar o idle.

### Priority

Define qué animación gana si dos se reproducen al mismo tiempo. Las prioridades de mayor a menor son: **Action → Movement → Idle → Core**.

---

## Cómo crear una animación

1. Abrís **Avatar → Animation Editor**
2. Seleccionás el personaje en el Workspace
3. Click en **+** para agregar un keyframe
4. Seleccionás una parte del cuerpo y la movés a la pose deseada
5. Avanzás en la línea de tiempo y repetís para el siguiente keyframe
6. Previsualizás con el botón **Play**
7. Publicás con **Save to Roblox** para obtener el ID

---

## Las animaciones de la misión

### Caminar (con Loop)

| Tiempo | Pose |
|---|---|
| 0s | Pose neutral |
| 0.5s | Pierna derecha adelante, brazo izquierdo adelante |
| 1s | Igual al 0s (cierra el loop) |

Activar **Loop** al terminar.

### Saludar (sin Loop)

| Tiempo | Pose |
|---|---|
| 0s | Pose neutral |
| 0.3s | Brazo derecho levantado |
| 0.6s | Brazo un poco abajo |
| 0.9s | Brazo arriba de nuevo |
| 1.2s | Pose neutral |

### Bailar

Libre y creativa. Cada alumno la hace a su manera.

## Previsualizar y publicar

| Acción | Cómo | Para qué |
|---|---|---|
| **Previsualizar** | Botón Play dentro del editor | Ver cómo queda antes de publicar |
| **Publicar** | Save to Roblox | Genera un ID para usar en Clase 14 |

> ⚠️ Anotá el ID de cada animación publicada. Lo vas a necesitar en la Clase 14.

---

## Misión

> Exportar (publicar) y previsualizar 2 animaciones propias.

**Lo que debe tener cada animación:**
- Al menos 3 keyframes
- Una animación con Loop y otra sin Loop
- Ambas publicadas con su ID anotado
