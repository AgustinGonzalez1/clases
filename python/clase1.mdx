## ¿Qué es Python?

Python es un lenguaje de programación — una forma de darle instrucciones a la computadora para que haga lo que nosotros queremos. Se usa para crear videojuegos, páginas web, aplicaciones, e incluso para que la inteligencia artificial funcione. Es uno de los lenguajes más usados del mundo porque es fácil de leer y de escribir, casi como si estuviéramos escribiendo en español o inglés con reglas simples.

**Ejemplo — así se ve una instrucción en Python:**

```python
print("Hola, mundo")  # muestra el texto en pantalla
```

Con esa sola línea, la computadora muestra el texto en pantalla. Eso es programar: escribir instrucciones que la computadora entiende y ejecuta paso a paso.

## Nuestro primer programa: `print()`

La función `print()` es la más usada en Python — le dice a la computadora "mostrá esto en pantalla". Todo lo que quieras mostrar va adentro de los paréntesis, y si es texto, entre comillas.

**Ejemplo — el clásico "Hola, mundo":**

```python
print("Hola, mundo")  # imprime el texto
```

**Ejemplo — se pueden hacer varios prints seguidos:**

```python
print("Hola, mundo")                  # primera línea
print("Estoy aprendiendo Python")     # segunda línea
print("¡Esto es genial!")             # tercera línea
```

Cada `print()` escribe en una línea nueva, en el orden en que aparecen en el código.

---

## Las comillas son importantes

El texto siempre va entre comillas — pueden ser simples `' '` o dobles `" "`, ambas funcionan igual.

**Ejemplo:**

```python
print("Esto funciona")           # comillas dobles
print('Esto también funciona')   # comillas simples
```

**Ejemplo — el error más común de la clase:**

```python
print(Hola mundo)     # ❌ Error — falta las comillas
print("Hola mundo")   # ✅ Correcto
```

Vale la pena mostrar este error en vivo para que lo reconozcan cuando les pase a ellos.

---

## Comentarios en el código

Un comentario es una línea que Python **ignora** — sirve para que nosotros (o quien lea el código) entendamos qué hace cada parte. Se escribe con el símbolo `#`.

**Ejemplo:**

```python
# Esto es un comentario, Python no lo ejecuta
print("Hola, mundo")   # esto sí se ejecuta
```

Los comentarios son como notas al margen — no cambian lo que hace el programa, pero ayudan a explicarlo.

---

## Emojis y símbolos también se pueden imprimir

**Ejemplo:**

```python
print("¡Bienvenido al curso! 🐍🎮")    # también se pueden imprimir emojis
print("Vamos a crear videojuegos 🚀")
```

Esto suele generar entusiasmo — mostrar que Python no es solo texto plano, sino que puede incluir emojis y símbolos libremente dentro de las comillas.
