# Clase 2: Creamos el encabezado 🛠️

## ¿Por qué el encabezado es tan importante?

Es lo primero que ve alguien al entrar a un sitio. Ahí suele estar el logo, el nombre y la navegación entre páginas.

## Analizando encabezados conocidos

Antes de programar, miramos encabezados de sitios reales (por ejemplo Amazon, Netflix, una tienda). ¿Qué tienen en común? Casi siempre: un logo a la izquierda y links de navegación a la derecha.

## La etiqueta `<nav>`

Agrupa los links de navegación del sitio. La forma actual y recomendada es envolver los links en una lista `<ul>`, no ponerlos sueltos. Esto ayuda a la accesibilidad (lectores de pantalla) y ordena mejor el código:

```html
<nav>
  <ul>
    <li><a href="#">Inicio</a></li>
    <li><a href="#">Proyectos</a></li>
    <li><a href="#">Contacto</a></li>
  </ul>
</nav>
```

## La etiqueta `<a>` y el atributo `href`

`<a>` crea un link. `href` indica a dónde lleva.

```html
<a href="https://google.com">Ir a Google</a>
```

Para páginas del mismo sitio, se pone el nombre del archivo:

```html
<a href="contacto.html">Contacto</a>
```

## Abrir un link en una pestaña nueva

Cuando el link lleva a otro sitio (no una página propia), suele convenir abrirlo en una pestaña nueva para no perder al usuario. Eso se hace con `target="_blank"`:

```html
<a href="https://instagram.com" target="_blank">Instagram</a>
```

Sin `target="_blank"`, el link se abre en la misma pestaña y el usuario sale de nuestro sitio. Con `target="_blank"`, se abre una pestaña nueva y el sitio original sigue abierto.

Importante: para links internos entre nuestras propias páginas (como `contacto.html`) no se usa, porque ahí sí queremos que navegue dentro del mismo sitio.

## El encabezado completo

```html
<header>
  <h1>Mi Sitio</h1>
  <nav>
    <ul>
      <li><a href="index.html">Inicio</a></li>
      <li><a href="proyectos.html">Proyectos</a></li>
      <li><a href="contacto.html">Contacto</a></li>
      <li><a href="https://instagram.com" target="_blank">Instagram</a></li>
    </ul>
  </nav>
</header>
```

## Creando varias páginas

Para que la navegación funcione de verdad, necesitamos más de un archivo HTML:

```
mi-sitio/
├── index.html
├── proyectos.html
└── contacto.html
```

Cada archivo tiene su propia estructura completa (con `<!DOCTYPE html>`, `<head>`, etc.) y el mismo `<header>` copiado en los tres.

## 📥 Misión de la clase

Crear el encabezado con logo y navegación, y dejar creadas al menos 2 páginas más (por ejemplo `proyectos.html` y `contacto.html`) para que los links funcionen de verdad.
