# Clase 1: Coordenadas, eje X e Y 🗺️

Aprendemos a ubicarnos en el escenario de Scratch usando números positivos y negativos.

## Contenido

### 1. ¿Qué son las coordenadas?

El escenario de Scratch es como un mapa con dos ejes:

| Eje   | Dirección  | Positivo | Negativo  |
| ----- | ---------- | -------- | --------- |
| **X** | Horizontal | Derecha  | Izquierda |
| **Y** | Vertical   | Arriba   | Abajo     |

El centro del escenario es el punto **(0, 0)**. Desde ahí, los números crecen o decrecen según hacia dónde vamos.

### 2. Bloques que usamos

| Bloque                                 | Qué hace                                      |
| -------------------------------------- | --------------------------------------------- |
| `ir a x: [ ] y: [ ]`                   | Lleva al sprite a una posición exacta         |
| `deslizar en [ ] segs a x: [ ] y: [ ]` | Mueve al sprite suavemente hasta esa posición |
| `posición en x` / `posición en y`      | Muestra en qué coordenada está el sprite      |

### 3. Exploración guiada

1. Abrir Scratch y seleccionar el sprite del gato
2. Usar el bloque `ir a x: 0 y: 0` — el sprite va al centro
3. Cambiar los valores de X y Y y observar hacia dónde se mueve
4. Probar valores negativos — ¿qué pasa?
5. Usar `deslizar en 1 segs` para verlo moverse suavemente

### 4. Referencia de posiciones

| Posición                   | X    | Y    |
| -------------------------- | ---- | ---- |
| Centro                     | 0    | 0    |
| Esquina superior derecha   | 240  | 180  |
| Esquina inferior izquierda | -240 | -180 |

## Misión

> Mover el sprite a las 4 esquinas del escenario usando bloques de coordenadas. Primero con `ir a`, después con `deslizar en`.
