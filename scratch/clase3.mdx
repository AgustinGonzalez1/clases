# Clase 3: Preguntas y respuestas 2 🏆

Convertimos las preguntas de la clase anterior en un juego de verdad: con puntaje, sonidos y un resultado final.

## Objetivos

- Crear y usar variables
- Diferenciar `fijar` de `cambiar`
- Agregar sonidos al juego
- Mostrar el puntaje final

## Contenido

### 1. ¿Qué es una variable?

Una variable es una cajita con nombre que guarda un número. Scratch se acuerda de ese número mientras el juego está funcionando.

**Ejemplo en la vida real:** cuando jugamos un juego de mesa anotamos los puntos en un papel. Cada vez que alguien acierta, sumamos uno. Ese papel es una variable.

### 2. Crear una variable

En la categoría **Variables** → botón **Crear una variable** → escribir el nombre.

**Ejemplo:** crear una variable llamada `puntos`. Aparece en el escenario mostrando su valor.

### 3. Fijar y cambiar

Hay dos formas de modificar una variable:

| Bloque                    | Qué hace                                                  |
| ------------------------- | --------------------------------------------------------- |
| `fijar [puntos] a [0]`    | Le pone un número exacto, sin importar el que tenía antes |
| `cambiar [puntos] en [1]` | Le suma 1 al número que ya tenía                          |

**Ejemplo:**

```
fijar [puntos] a [0]      ← puntos vale 0
cambiar [puntos] en [1]   ← puntos vale 1
cambiar [puntos] en [1]   ← puntos vale 2
fijar [puntos] a [0]      ← puntos vuelve a 0
```

### 4. Empezar siempre en cero

Si no reiniciamos la variable al empezar, los puntos se acumulan de una partida a la otra.

**Ejemplo:**

```
al presionar 🏴
fijar [puntos] a [0]
```

### 5. Sumar un punto al acertar

Ponemos el `cambiar puntos en 1` adentro del `si`, así solo suma cuando la respuesta es correcta.

**Ejemplo:**

```
preguntar [¿Cuánto es 2 + 2?] y esperar
si <(respuesta) = [4]> entonces
   cambiar [puntos] en [1]
   decir [¡Correcto!] durante [2] segundos
si no
   decir [Era 4] durante [2] segundos
```

### 6. Agregar sonidos

En la pestaña **Sonidos** (arriba) → botón de abajo a la izquierda → **Elige un sonido**. Elegimos uno para acertar y otro para errar.

Después usamos el bloque `iniciar sonido` (categoría **Sonido**).

**Ejemplo:**

```
si <(respuesta) = [4]> entonces
   cambiar [puntos] en [1]
   iniciar sonido [Win]
   decir [¡Correcto!] durante [2] segundos
si no
   iniciar sonido [Boing]
   decir [Era 4] durante [2] segundos
```

### 7. El resultado final

Al terminar todas las preguntas, el personaje dice cuántos puntos hicimos arrastrando la variable `puntos` adentro del `decir`.

**Ejemplo:**

```
decir (puntos) durante [3] segundos
```

### 8. Todo junto

```
al presionar 🏴
fijar [puntos] a [0]

preguntar [¿Cuál es la capital de Argentina?] y esperar
si <(respuesta) = [Buenos Aires]> entonces
   cambiar [puntos] en [1]
   iniciar sonido [Win]
   decir [¡Bien!] durante [2] segundos
si no
   iniciar sonido [Boing]
   decir [Era Buenos Aires] durante [2] segundos

preguntar [¿Cuánto es 5 x 3?] y esperar
si <(respuesta) = [15]> entonces
   cambiar [puntos] en [1]
   iniciar sonido [Win]
   decir [¡Bien!] durante [2] segundos
si no
   iniciar sonido [Boing]
   decir [Era 15] durante [2] segundos

decir (puntos) durante [3] segundos
```

## Ejercicio

> Consigna: Armá un juego de al menos 3 preguntas que sume un punto por cada acierto, tenga un sonido para acertar y otro para errar, y diga el puntaje al terminar.

**Pistas:**

1. Poné `fijar puntos a 0` al principio para que no se acumulen de una partida a otra
2. El `cambiar puntos en 1` va adentro del `si`, no en el `si no`
3. Arrastrá la variable `puntos` adentro del `decir` para mostrar el resultado
