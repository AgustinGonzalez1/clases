# Clase 12: Wick Editor 3 🖱️

Le damos interactividad a nuestros dibujos: escribimos nuestras primeras líneas de código en JavaScript para que un objeto cambie cuando le hacemos clic.

## Objetivos

- Convertir un dibujo en un botón
- Escribir código que reaccione al clic
- Cambiar tamaño, rotación, posición y transparencia con código
- Exportar la animación terminada

## Contenido

### 1. De los bloques al texto

En Scratch damos órdenes arrastrando bloques de colores. En Wick Editor las mismas órdenes se escriben con palabras. Es lo mismo dicho de otra forma.

**Ejemplo en la vida real:** es como la diferencia entre hacer señas y hablar. Los dos comunican lo mismo.

### 2. Convertir un dibujo en botón

Dibujamos algo, lo seleccionamos con la flecha y hacemos **clic derecho → Create Button**. Solo los botones pueden reaccionar al clic.

**Ejemplo:** dibujar un círculo de color, seleccionarlo y convertirlo en botón.

### 3. Abrir el editor de código

Con el botón seleccionado, en el **Inspector** (derecha) aparece la sección **Scripts**. Hacemos clic en **Mouseclick** y se abre el editor.

> Arriba tiene que decir **"Code Editor | editing button"**. Si dice otra cosa, el código está puesto en el lugar equivocado y no va a funcionar.

### 4. Mover el objeto al hacer clic

`this` significa "este objeto". `this.x` es su posición horizontal, igual que la X de Scratch.

**Ejemplo:**

```javascript
this.x = this.x + 20;
```

Cada clic mueve el objeto 20 hacia la derecha.

### 5. Moverlo para arriba

`this.y` es la posición vertical. En Wick Editor, restar hace que suba.

**Ejemplo:**

```javascript
this.y = this.y - 30;
```

### 6. Agrandar y achicar

`scaleX` y `scaleY` son el tamaño a lo ancho y a lo alto. Hay que cambiar los dos juntos para que no se deforme.

**Ejemplo:**

```javascript
this.scaleX = this.scaleX + 0.1;
this.scaleY = this.scaleY + 0.1;
```

Para achicar, se usa `- 0.1`.

### 7. Rotar

`rotation` es el giro, medido en grados.

**Ejemplo:**

```javascript
this.rotation = this.rotation + 30;
```

### 8. Volverse transparente

`opacity` va de 1 (se ve entero) a 0 (invisible).

**Ejemplo:**

```javascript
this.opacity = this.opacity - 0.1;
```

### 9. Combinar varios efectos

Se pueden poner varias órdenes seguidas: se ejecutan todas con el mismo clic.

**Ejemplo:**

```javascript
this.scaleX = this.scaleX + 0.1;
this.scaleY = this.scaleY + 0.1;
this.rotation = this.rotation + 30;
```

### 10. Cambiar de color con frames

El color no se cambia directamente con código. El truco es dibujar el objeto de un color en el frame 1 y de otro color en el frame 2, y saltar de un frame al otro.

**Ejemplo:**

```javascript
this.gotoAndStop(2);
```

### 11. Exportar la animación

Botón **Export** arriba a la derecha → **Animated GIF** (Graphics Interchange Format) → se descarga el archivo. Es la primera vez que producimos algo que se puede compartir fuera del programa.

## Ejercicio

> Consigna: Creá un objeto interactivo que reaccione al clic con al menos dos efectos combinados, y exportá tu animación como gif.

**Pistas:**

1. Si no aparece la sección Scripts, el dibujo todavía no es un botón
2. Fijate que arriba del editor diga "editing button"
3. Cada orden termina con punto y coma
